# 견적문의 구조 결정

대상: `quote.html`(비회원 안내 · 대화형 입력 · 한 화면 입력 양식 · 상품 검색 팝업), `quote-intro.html`(견적문의 안내)
본 캡처: `research/refs/quote-form/`의 숨고 요청서(PC·모바일 6장), LG전자 B2B 견적(양식·안내 팝업), 샵다나와 PC견적(PC·모바일), GOV.UK 예시 4종, MOJ "Add another". 기록은 같은 폴더의 `notes.md`.

## 캡처에서 확인한 사실

| 곳 | 본 것 |
|---|---|
| 숨고 요청서 | 답한 질문은 "질문(왼쪽 말풍선) → 내 답(오른쪽 말풍선) → 답 아래 오른쪽 '수정'"으로 쌓인다. 지금 질문만 흰 카드(PC 약 400px)로 열리고 카드 안은 질문 → 선택지(한 줄에 하나, 전체 폭) → 맨 아래 전체 폭 "다음"(답 전에는 비활성). 선택 질문은 "건너뛰기"(왼쪽, 좁게) + "다음"(오른쪽, 넓게)이고 건너뛰면 "건너뛰기를 선택했어요." 답이 남는다. "수정"을 누르면 그 자리에서 카드가 다시 열리고 링크는 "수정 취소"가 된다. 뒤 답과 진행률은 그대로다. 위쪽에 양식 이름 + 가는 진행 막대 + 오른쪽 끝 %가 붙어 있다(60% → 69% → 77%). |
| LG 견적 | 한 화면 긴 양식. 고른 제품 값이 아래 "제품문의" 묶음에 읽기 전용으로 다시 보인다. "안내 보기" 팝업은 단계마다 "번호 · 제목 · 설명 두 줄(왼쪽) + 화면 그림(오른쪽)" 한 줄씩이다. 모바일에서 라벨이 칸 위로 올라가 한 열이 된다. |
| 샵다나와 | PC 2열: 왼쪽 약 845px에서 검색해 고르고, 오른쪽 약 400px "견적카트"에 품목별로 쌓인다(상품명 · 수량 · ×). 맨 아래 "총 2개 품목선택 · 전체삭제" → 합계 → 버튼. 결과 줄은 "사진 · 상품명 · 규격 · 가격 · 담기"이고 담으면 "해제"로 바뀐다. 모바일은 요약이 빠지고 별도 화면이 된다. |
| GOV.UK | 오류 요약 상자가 제목 위에 오고 문장마다 해당 칸 링크, 칸 위에 같은 문장. 작업 목록은 끝난 것은 글자만, 안 끝난 것만 표식. 자동완성은 칸 바로 아래 같은 폭, 스크롤바 없이 9줄, 아래 방향키로 첫 줄 강조. |
| MOJ | 묶음 제목에 "Participant 1 of 2", 묶음 아래 "Remove participant 1", 마지막에 "Add another participant", 오류 문장에 몇 번째 묶음인지 들어 있다. |

## 대화형 입력

후보
1. 한 화면에 질문 하나씩(GOV.UK 질문 화면, Typeform): 이전 답이 안 보여 "답한 질문으로 돌아가 수정"(L621)을 하려면 뒤로 여러 번 가야 한다.
2. 가운데 한 열 대화(숨고 그대로, 폭 600): 흐름은 맞지만 PC 1280 틀에서 양옆이 비고, 이용 안내(L593)와 진행률(L594)을 둘 자리가 대화 위뿐이라 대화가 아래로 밀린다.
3. 왼쪽 대화 열 + 오른쪽 붙어 따라오는 안내 열: 대화는 숨고 구조, 오른쪽에 진행률 · 이용 안내 · 견적서 미리보기.

결정: 3번
- PC(1024 이상)는 `대화 열(최대 760) + 오른쪽 열 340`, 사이 56. 오른쪽 열은 `position:sticky`로 헤더 아래에 붙는다. 순서는 진행률(백분율 + 막대 + "답한 질문 9 / 20") → 이용 안내(펼친 채, 접을 수 있음) → "견적서 미리보기" 선 버튼. 근거: 요소 목록이 진행률 · 이용 안내(열고 닫기) · 미리보기를 요구하고, 숨고는 진행률을 위쪽에 고정해 대화가 길어져도 보이게 했다. 우리는 PC 옆 열이 그 역할을 한다.
- 1023 이하는 한 열. 진행률은 숨고 모바일처럼 헤더 아래 붙는 얇은 띠(글자 "견적문의 작성 · 45%" + 2px 막대)로 바꾸고, 이용 안내는 대화 위에 접힌 한 줄(`details`)로 둔다.
- 대화 한 덩어리 = 질문 말풍선(왼쪽, 회색 바탕 `#F5F5F6`, 최대 폭 80%) → 내 답(오른쪽, 검정 바탕 흰 글자) → 답 아래 오른쪽 "수정" 글자 버튼. 건너뛴 질문은 흰 바탕 1px 선 말풍선 "건너뛰었습니다."로 남긴다(숨고의 건너뛰기 답 줄).
- 지금 질문만 흰 카드(1px 선, 모서리 16, 최대 560)로 연다. 카드 안 순서: 질문(16/700) → 짧은 도움말 → 입력 → 맨 아래 버튼 줄. 선택 질문은 `건너뛰기(선 버튼) + 다음(검정, 남은 폭)`, 필수 질문은 `다음`만. 답을 넣기 전에는 "다음"을 누를 수 없다.
- 선택지는 한 화면 양식과 같은 알약(`.seg`, 높이 44, 줄바꿈)으로 모두 펼친다. 설명이 필요한 질문(상품 유형, 인쇄 여부)은 설명을 카드 도움말 한 줄로 옮긴다. 근거: DESIGN.md "조작 요소는 알약 하나로 통일", 두 방식이 같은 선택지를 같은 모양으로 보여야 한다. 숨고처럼 카드 안에서만 스크롤되는 목록은 쓰지 않는다(잘린 선택지가 안 보인다).
- 수정: 숨고 그대로. 그 질문이 제자리에서 카드로 다시 열리고 전에 고른 값이 들어 있다. 답 말풍선은 남고 "수정"이 "수정 취소"로 바뀐다. 뒤 답과 진행률은 그대로 둔다. 예외 두 가지만 요소 목록대로 처리한다: 상품 유형을 바꾸면 그 상품의 뒤 답을 지우고(L602), "다른 상품도 함께 문의" 답을 "아니요"로 바꾸면 뒤 상품을 지우기 전에 확인 창을 띄운다.
- 진행률: 지금 경로(상품 유형·인쇄 여부·상품 수에 따라 질문 수가 바뀐다)의 질문 중 답하거나 건너뛴 비율. 숨고는 %만 보여 남은 양을 알기 어려웠으므로 "답한 질문 9 / 20"을 함께 적는다.
- 상품 반복: 숨고에 없어서 MOJ 방식을 빌린다. "다른 상품도 함께 문의할까요?"에 "예"를 고르면 "2번째 상품" 구분 줄이 들어가고, 그 뒤 질문 말풍선마다 위에 작은 칩 "2번째 상품"을 붙인다(L598).
- 상품 검색 질문: 카드 안에 검색 칸(자동완성)과 결과 다섯 줄(사진 · 상품명 · 사이즈 범위 · 가격 · 선택)을 바로 보이고, 더 있으면 "결과 n개 모두 보기"로 상품 검색 팝업을 연다. 찾는 중 · 결과 없음 · 불러오기 실패는 같은 카드 안에 한 줄 안내로 바꾼다. 결과 없음에는 "앞 질문 고치기"(상품 유형 질문을 바로 연다)를 둔다(L631).
- 상대 입력 중 표시: 답한 뒤 다음 질문이 나오기 전 0.45초 동안 점 세 개 말풍선. 움직임 줄이기 설정이면 바로 다음 질문을 보인다.
- 마지막 단계: 연락받을 정보(회사명·담당자·연락처, 회원 정보로 채움) → 요청사항 → 마지막 카드("입력한 내용을 확인한 뒤 보내 주세요" + 미리보기 안내 + `견적서 미리보기` 선 버튼 + `견적문의 보내기` 검정 버튼). 파란 버튼은 쓰지 않는다. 폰 하단 상담 바의 "견적문의"가 이미 파랑이라 한 화면에 둘이 된다.

## 한 화면 입력 양식(?mode=form)

후보
1. 한 열 긴 양식(LG): 상품이 여러 개면 지금까지 무엇을 넣었는지 보려고 다시 올라가야 한다.
2. 2열 + 오른쪽 요약(샵다나와): 왼쪽에서 상품 블록을 채우고 오른쪽 요약이 따라온다.

결정: 2번
- PC(1024 이상): 왼쪽 양식 열 + 오른쪽 요약 열 360(sticky), 사이 48. 1023 이하는 요약을 양식 아래 "다음" 버튼 바로 위로 옮긴다(샵다나와 모바일처럼 따로 떼어 두되, 하단 상담 바가 이미 있어 고정 바를 하나 더 쌓지 않는다).
- 양식 맨 위에 단계 표시(`ol.stp`): 상품 정보 → 연락처 정보 → 견적서 확인. 스크롤 위치로 지금 보는 단계를 굵게, 필수값을 다 채운 단계에 완료 표시(L646). 견적서 확인은 미리보기 창에서 한다.
- 상품 블록(MOJ): 제목 "상품 1 / 2" + 오른쪽 끝 "삭제"(상품이 하나뿐이면 숨김). 블록 안 순서: 상품 유형(알약 둘) → 상품명(쇼핑몰 내 상품이면 누르면 검색 팝업이 열리는 칸, 고르면 사진 · 이름 · 품번 · 사이즈 범위 줄로 바뀌고 "다시 고르기") → 첨부(쇼핑몰에 없는 상품이거나 넘겨받은 파일이 있을 때만) → 수량 · 옵션(한 줄 두 칸) → 포장 · 인쇄방법(알약) → 인쇄 부위 및 설명 → 납품희망일 · 기타사항. 블록 사이 1px 선, 마지막 블록 아래 "상품 추가".
- 폰에서는 상품 블록 머리를 눌러 접고 펼친다. 처음에는 마지막 블록만 펼쳐 두어 화면 길이를 줄인다(접힌 블록 머리에 "상품명 · 수량"이 보인다).
- 요약(L648~652): 필수값 채운 비율(백분율 + 막대 + "필수 7 / 9") → 상품별 한 줄(번호 · 상품명, 없으면 "상품 2" · 수량, 없으면 "비어 있음") — 덜 채운 줄에만 "입력 필요" 칩(GOV.UK 작업 목록 규칙) → 상품·디자인 이미지 전체 개수 → 회사명 · 담당자 · 연락처 → `다음` 검정 버튼.
- 검사(L685): "다음"을 누르면 양식 맨 위에 오류 요약 상자(문장마다 해당 칸으로 가는 링크, "2번째 상품을 골라 주세요."처럼 순번)를 열고 해당 칸 아래에도 같은 문장을 붙인다(GOV.UK + MOJ). 통과하면 새 창으로 `quote-preview.html`. 상태는 세 벌로 나눠 본다: `err`(상품 미선택·수량·파일 20MB), `err-attach`(상품당 5개 초과·전체 20개·합계 100MB, 넘은 수와 용량을 문장에 적고 요약의 이미지 줄을 빨갛게), `err-empty`(상품 0개·회사명·담당자·연락처 비어 있음). 첨부 문제가 남아 있으면 단계 표시 1단계에 완료 표시를 하지 않는다.
- 평일 고객상담 전화번호와 전화상담 · 카카오톡 상담(L645, L678, L679)은 페이지 머리 오른쪽에 둔다(`.sub-head--row`). 입력하다가 막힐 때 위로 한 번만 올라가면 된다.

## 상품 검색 팝업

- 큰 팝업(`.pop__box--l`, 폰은 화면 가득). 위에 검색 칸(지우기 × + 검색 버튼), 칸 바로 아래 같은 폭 자동완성(최대 6줄, 사진 40 · 상품명에서 검색어 굵게 · 분류, 방향키 · Enter · Esc, 스크롤바 없음) — GOV.UK 자동완성 + Baymard 줄 수 기준.
- 그 아래 "추천 상품"(검색어 없을 때, 무작위 20개) 또는 "'패딩' 검색 결과 13개". 결과는 PC 2열 줄 목록(샵다나와 결과 줄): 사진 72 · 분류 · 상품명(누르면 상품 상세가 새 창) · 사이즈 범위 · 색 점 최대 5개 + 남은 수 · 가격(없으면 "견적문의") · 오른쪽 "선택". 폰은 1열.
- 찾는 중(뼈대 줄), 결과 없음, 등록된 상품 없음, 검색어 100자 초과, 불러오기 오류는 결과 자리 한 덩어리 안내(`.empty`)로 바꾼다.

## 비회원 안내(state=guest)

- 회원 전용 화면은 `.gate`처럼 가운데 한 줄 안내만 두지 않는다. 페이지 머리 아래 2열: 왼쪽 상자에 잠금 표식 → "견적문의는 회원만 이용할 수 있습니다." → 소개 → 로그인(검정) · 회원가입(선) → 간편 로그인 세 개 → 구분선 → 전화상담 · 카카오톡 상담. 오른쪽에 진행 3단계 미리보기(견적문의 안내와 같은 이름 · 설명), 1단계에 "지금 단계" 표시. 다나와가 요약 머리에서 로그인을 권한 것처럼, 무엇을 하게 되는지 보여 주며 로그인을 권한다.

## 견적문의 안내(quote-intro)

- 머리(`.sub-head--row`): 왼쪽 제목 · 소개 문장 · 평균 답변 시간(영업일 기준 1~2일), 오른쪽 "견적문의 하러 가기" 검정 버튼.
- 진행 3단계: PC 3열 카드(사진 4:3 모서리 16 → "1단계" 작은 글자 → 단계 이름 17/700 → 설명 14). 사진 아래 글 높이를 맞춰 카드 높이를 같게 둔다. 폰은 사진 104px 왼쪽 + 글 오른쪽 줄 세 개로 줄인다(LG 안내 팝업의 "번호·제목·설명 + 그림" 한 줄 구성). 번호는 단계 이름 위 13px 글자로만 쓰고 크게 장식하지 않는다.
- 그림 자료가 없어 상품 사진(1·2단계)과 현장 연출 사진(3단계)을 쓰고 `data-slot="quote-step-1~3"`을 붙인다. 연출 사진에는 "연출 이미지입니다."를 붙인다.
- 참고 사항은 `.note` 목록 하나, 그 아래 가운데 "견적문의 하러 가기"를 한 번 더 둔다. 비회원 상태에서는 머리 버튼 옆에 회원 전용 안내 한 줄과 로그인 버튼을 보인다.

## 만들면서 고친 것
- 단계 그림 1단계를 색상 견본 사진(흰 바탕 + 영문 색 이름)에서 회색 스튜디오 모델 사진(`img/products/md-pick-463.webp`)으로 바꿨다. 세 장이 모두 사진이어야 카드 높이와 인상이 고르다.
- 비회원 안내의 3단계 설명을 견적문의 안내와 글자까지 같게 맞췄다(요소 목록 L579 "같은 단계 이름·설명").
- 비회원 안내 사진의 "연출 이미지입니다."를 밝은 벽 위(오른쪽 위)에서 아래쪽 어둠 그라데이션 위(오른쪽 아래)로 옮겼다. 흰 글자가 읽히지 않았다.
- 상품 상세에서 넘어온 인쇄방법이 우리 선택지에 없으면(상품 상세는 자수·실크·전사) 선택지 네 번째 자리에 더한다. 대화형·한 화면 양식 모두 같다(L610, L663).
- 상품 검색 팝업을 대화형에서 연 상태(`state=search+pick`)를 더했다. 두 방식이 같은 팝업을 쓴다는 것을 상태 목록에서 바로 볼 수 있다.
- 머리의 평일 고객상담 묶음이 1024에서 제목 아래로 떨어지던 것을 왼쪽 글 묶음이 줄어들게 고쳐 한 줄로 유지했다(폰에서만 아래 회색 상자로 내려간다).

## 검수 뒤 고친 것(2026-11-17 오후)
- 대화형 선택지를 사각 카드(`.opt`)에서 알약(`.seg.qt-seg`, 44)으로 바꿨다. 한 화면 양식과 같은 모양이다.
- 수량 −/+를 사각 버튼에서 44 원형 버튼(inset 1px 선)으로, 가운데 숫자 칸을 입력칸 모양(12px, 오류 때 빨간 선)으로 바꿨다. 대화형·양식 공통.
- 대화형 첨부: 전체 20개·합계 100MB 오류가 실제 오류 줄로 나오는 상태 `state=attach-total`(5번째 상품, 앞 상품 네 개에 17개·96.0MB)을 더했다. 앞 상품에 파일이 있으면 첨부 카드 아래에 "지금 모든 상품 합계 n / 20개 · x / 100MB"를 보인다.
- 사진 모서리를 16px(폰 14px)로 맞췄다(답 말풍선 속 상품 사진, 검색 결과·자동완성 사진). 편집 중 안내 말풍선도 16px.

## 가져오지 않는 것
- 숨고의 사이즈별 수량 줄: 요소 목록의 수량은 숫자 하나(L606)이고 사이즈는 옵션 글(L607)에 적는다.
- 숨고의 납품 날짜 선택지(협의 가능 / 빨리 / 일주일 이내): 요소 목록은 날짜 하나(L613)다.
- LG의 홍보 배너, 약관 본문 펼침, 다나와의 합계 금액 · 견적 저장/공유: 요소 목록에 없다.
- 대화형과 한 화면 양식을 오가는 전환 링크: 요소 목록에 없다(질문 기록에 적었다).
