# 상품 목록형 구조 결정

대상: `category.html`(단체복·작업복 상품 목록), `brand.html`(협력브랜드 상품 목록), `search.html`(검색 결과)

## 구조 후보

1. **왼쪽 옆 분류 + 위 필터 줄** (코오롱몰): 분류가 많을 때 좋지만 상품 칸이 좁아져 홈의 4열 카드(305px)와 크기가 달라진다.
2. **필터를 전부 펼쳐 두기** (무신사): 한눈에 보이지만 필터 6종이 화면 위쪽을 3~4줄 차지한다. 사진이 이끄는 홈의 인상과 다르고 모바일이 길어진다.
3. **대표 사진 → 세부 분류 알약 줄 → 필터 버튼 한 줄 + 정렬 → 4열 격자** (Strauss의 순서 + 코오롱몰의 필터 방식 + 홈의 알약 줄): 위에서 아래로 좁혀 가는 순서이고 홈의 부품을 그대로 쓴다.

## 결정: 3번

- **순서**: 경로 → 분류 소개(대표 사진 위에 머리글·분류 이름·설명·견적 문의하기) → 세부 분류 → 도구 줄(상품 수 · 필터 버튼 · 정렬) → 고른 필터 → 상품 격자 → 쪽 번호.
  - 근거: 요소 목록이 분류마다 대표 사진과 소개 글(머리글·제목·설명)을 요구한다. Strauss가 같은 요소를 맨 위 사진 한 장으로 풀었다. 홈의 겨울 시즌 배너(`.ss__hero`)와 같은 글자 배치(앞말 가늘게 + 이름 굵게)를 쓰면 `DESIGN.md`의 "영문 라벨 금지, 제목은 앞말 + 이름" 규칙도 지킨다. 페이지 제목(h1)을 이 배너 안에 두어 분류 이름이 두 번 나오지 않게 한다.
  - 배너 높이는 홈 배너(457px)보다 낮춘다(PC 280px 안팎, 폰 3:2). 목록 페이지는 상품이 첫 화면에 보여야 한다.
  - 사진이 여러 장인 분류(라운드 티셔츠·작업복)는 같은 배너 안에서 이전·다음 버튼, 끌어서 넘기기, 진행 막대(홈의 `.md__prog`)를 쓴다. 자동으로 넘기지 않는다(사장님이 자동으로 흘러가는 띠를 싫어한다).
- **세부 분류**: 홈의 떠 있는 알약 줄(`.bh`)을 쓰고 헤더 아래에 붙는다. 48개를 내려 보다가도 분류를 바꿀 수 있다. 네파·SSF샵처럼 제목 바로 아래 두는 위치는 같다. 폰에서는 옆으로 민다.
- **필터**: 코오롱몰 방식.
  - PC: 필터 종류 6개(소재·형태·색상·사이즈·가격대·시즌)를 버튼 한 줄로 두고, 누르면 그 종류의 선택지만 버튼 아래에 뜬다. 뜬 상자 아래에 `초기화`와 `적용`. 한 번에 한 종류만 열린다(요소 목록 "한 번에 한 종류만").
  - 폰: 버튼 줄을 옆으로 밀고, 누르면 화면을 채우는 필터 모음이 열린다. 위에 종류 탭(바로 이동), 한 번에 한 종류, 아래에 `초기화 / N개 상품 보기` 고정.
  - 고른 종류의 버튼에는 개수를 붙이고(묶음별 적용 여부 표시), 고른 값은 도구 줄 아래에 칩으로 나열해 하나씩 빼거나 전부 뺄 수 있다. 색상 칩에는 색 견본을 붙인다.
  - 필터를 전부 펼치지 않는 근거: 6종을 다 펼치면 3줄 이상이다. 옆 패널 하나로만 두지 않는 근거: PC에서는 필터가 가려지면 쓰임이 줄어든다는 Baymard의 지적(기록의 "사용성 근거")과 코오롱몰·SSF샵·Strauss 세 곳이 모두 버튼 줄을 쓴다는 점.
- **상품 수와 정렬**: 도구 줄 왼쪽에 상품 수(SSF샵·네파·Strauss 공통), 오른쪽에 정렬 세 가지를 글자로 나란히 둔다. 선택지가 셋뿐이라 펼침 목록보다 한 번에 보이는 편이 빠르다.
- **격자**: 홈과 같은 `.pgrid`(PC 4열, 1024 이하 3열, 폰 2열, 사이 48/20 · 32/12). 카드는 홈의 `.pc` 그대로. 코오롱몰·SSF샵의 5~6열은 쓰지 않는다(홈 카드 크기와 달라진다).
- **작업복 베스트 / 브랜드 베스트**: 격자 위에 한 줄(작업복 최대 8개는 옆으로 넘기는 줄, 브랜드 최대 6개는 6칸). 격자 카드보다 작게 해서 본 목록과 구분한다.
- **협력브랜드**: 브랜드 고르기는 홈의 로고 알약 줄(`.bh--logo`) 그대로. 형태는 묶음(의류·작업복 / 안전·보호구 / 기타)마다 한 줄씩 칩으로 두고 이름 옆에 상품 수를 붙인다. 코오롱몰의 왼쪽 옆 분류는 쓰지 않는다(상품 칸 폭이 분류 목록과 달라지고, 형태가 없는 브랜드에서는 옆 칸이 빈다).
- **검색 결과**: 대표 사진 없이 제목(`'패딩' 검색 결과`)과 상품 수만 둔다. 나머지는 분류 목록과 같은 도구 줄·격자.
- **결과 없음**: 격자 자리에 안내 한 덩어리(무신사의 결과 없음 화면처럼 문장 + 다음 행동). 필터가 걸려 있으면 `필터 초기화`, 검색·브랜드에서는 `견적문의`로 가는 버튼을 둔다.

## 가져오지 않는 것
- 무신사·SSF샵의 할인율·별점·찜 수 표시: 요소 목록에 없다.
- 네파 모바일의 화면 아래 떠 있는 정렬·필터 알약: 우리 폰 화면 아래에는 이미 상담 바가 있다.
- Strauss의 "Jacket finder"(추천 도우미): 요소 목록에 없다.
