# 상품 목록형(list) 레퍼런스 조사 기록

- 본 날짜: 2026-11-17
- 대상 우리 페이지: 단체복·작업복 상품 목록, 협력브랜드 상품 목록, 검색 결과
- 본 방법: Playwright(Chromium)로 PC 1440×900, 모바일 390×844(배율 2)에서 직접 열어 찍고, 찍은 그림을 열어 본 뒤 적었다. 순서는 `_capture.py` 의 FLOWS 에 남겼다.
- 아래 "관찰한 사실"은 이 폴더에 저장한 캡처에서 본 것만 적었다. px 값은 캡처에서 잰 대략값이다.
- 캡처를 볼 때 알아 둘 점
  - 전체 화면 캡처(`*-list-*`, `*-brand-*`, `*-empty-*`)에는 화면 아래 고정 띠(모바일 하단 메뉴, 떠 있는 버튼)가 첫 화면 높이 자리에 한 번 찍혀 있다. 실제로는 화면 아래에 붙어 있는 것이다.
  - 무신사 목록은 화면에 보이는 줄만 그리는 방식이라 아래쪽이 빈 화면으로 찍혀 잘라 냈다(PC 4줄, 모바일 약 7줄까지).
  - 코오롱몰 모바일 목록은 7줄(21개) 아래가 그려지지 않아 잘라 냈다. 코오롱몰 브랜드관 모바일의 BEST 구역은 빈 칸으로 찍혔다.
  - Strauss 는 처음 열면 쿠키 동의 창이 목록을 가린다. "Reject all"을 눌러 닫고 찍었다.
- 이번에 하지 않은 것: 가격대 필터와 정렬 메뉴(PC)는 펼쳐 보지 않았다. 디자인 어워드·패턴 모음 사이트는 보지 않았고, 운영 중인 사이트와 Baymard·NN/g 글만 봤다.

## 1. 코오롱몰 — 워크웨어 분류 목록

- 주소: https://www.kolonmall.com/Category/List/133010210000
- 본 날짜: 2026-11-17
- 캡처: `kolonmall-list-pc.jpg`, `kolonmall-list-m.jpg`, `kolonmall-filter-pc.jpg`, `kolonmall-filter-m.jpg`, `kolonmall-filter-all-pc.jpg`, `kolonmall-applied-pc.jpg`, `kolonmall-applied-m.jpg`

관찰한 사실 — PC

- 정보 순서: 헤더 → 왼쪽 열(폭 약 200px)에 분류 이름 "워크웨어"와 세부 분류 세로 목록(ALL·의류·용품·안전화. 고른 항목은 굵은 글자 + 오른쪽 체크) / 오른쪽 본문에 "추천브랜드" 칩 2개 → 1px 선 → 필터 버튼 줄(모든필터·큼페이백·성별·브랜드·컬러·사이즈·가격 및 할인·상세정보) + 같은 줄 오른쪽 끝 정렬("추천순 ▾") → 상품 격자 → 쪽 번호. 첫 상품 사진은 318px 지점에서 시작한다.
- 격자: 5열 × 12줄 = 한 쪽 60개. 카드는 세로형 사진 → 브랜드(회색 작은 글자) → 상품명 → 가격(굵게) → 표식(베스트·신상품) → 좋아요 수와 별점.
- 필터 여는 방식: 필터 이름 버튼을 누르면 그 버튼 바로 아래에 상자(폭 약 380px)가 뜬다. 컬러 상자는 원 견본 19개를 5열로 놓고 견본 아래에 영문 색 이름(BEIGE, BLACK …)을 적었다. 고른 값은 견본 안 체크 + 바깥 고리로 표시한다.
- 상자 맨 아래에 "초기화"와 "378개 상품보기" 버튼이 있다. 값을 두 개 고르자 "163개 상품보기"로 바뀌었다. 이 버튼을 누르기 전에는 뒤의 목록이 바뀌지 않는다. 누른 횟수: 버튼 → 값 → 상품보기 = 3번.
- 모든필터: 왼쪽에서 나오는 서랍(폭 약 383px)이고 뒤 화면은 어두워진다. "필터" 제목 + 닫기 → 종류 탭 줄(혜택·성별·브랜드·컬러 2·사이즈·가격 및 할인 …. 고른 개수가 탭 이름 옆에 붙는다) → 본문은 모든 종류가 세로로 이어진다(혜택 → 성별 → 브랜드 → 컬러 …) → 맨 아래 고정 "초기화" + "163개 상품보기".
- 서랍의 브랜드 구역: 브랜드명 입력칸 → 묶음 글자 탭(추천·전체·오리지널·셀렉티드) → 브랜드 버튼 2열.
- 적용 뒤: 값을 고른 필터 버튼이 줄 맨 앞으로 옮겨지고 검정 테두리 + 굵은 글자 + 개수("컬러 2")가 된다. "모든필터 2"도 같다. 버튼 줄 아래에 회색 띠가 생기고 "BLACK ×", "NAVY ×" 칩이 왼쪽에, "초기화"가 오른쪽 끝에 있다. 주소에 `colors=BLACK,NAVY` 가 붙는다.
- 쪽 번호: 가운데 정렬, 원 안 숫자 1~7, 현재 쪽은 색을 채운 원. 이 목록(7쪽)에서는 이전·다음 화살표가 보이지 않는다.

관찰한 사실 — 모바일

- 정보 순서: 앱 열기 띠 → "← 워크웨어 ▾" + 검색·장바구니 → 세부 분류 가로 탭(ALL·의류·용품·안전화. 고른 탭은 굵게 + 밑줄) → 추천브랜드 칩 → 필터 줄(원 모양 아이콘 버튼 | 큼페이백·성별·브랜드·컬러·사이즈 …, 가로로 밀어 봄) → 정렬("추천순 ▾", 왼쪽) + 보기 전환 아이콘(오른쪽) → 3열 격자. 첫 상품 사진은 약 340px 지점.
- 필터: 아래에서 올라오는 시트(화면의 약 90%, 위에 손잡이 막대). 맨 위 종류 탭 줄이 누른 종류("컬러")에 맞춰져 열린다. 본문은 PC 서랍처럼 모든 종류가 한 화면에 이어진다(컬러 5열 견본+이름 → 사이즈: "상의/아우터" 소제목 + 2열 사각 버튼 …).
- 값을 고르면 아래 고정 버튼 바로 위에 고른 값 띠("BLACK ×  NAVY ×")가 생긴다. 맨 아래 "초기화" + "163개 상품보기".
- 적용 뒤: 필터 아이콘에 숫자 배지 2, "컬러 2 ×" 알약이 줄 맨 앞으로 오고 검정 테두리가 된다. 목록 화면에는 값 이름(BLACK·NAVY) 칩이 따로 없다.
- PC와 달라지는 점: 왼쪽 세로 분류 → 가로 탭, 버튼 아래 상자 → 시트, 값 칩 띠 → 시트 안으로, 5열 → 3열.

가져올 것

- 필터 이름 버튼을 한 줄로 놓고 버튼 아래에 상자를 띄우는 방식. 필터 6종이 한 줄에 들어가고, 격자 폭을 줄이지 않는다.
- 상자 맨 아래 "초기화 + N개 상품보기". 누르기 전에 몇 개가 남는지 알 수 있어 0개 결과로 가는 일을 줄인다.
- 색 견본 5열 + 견본 아래 이름. 색을 눈으로 고르고 이름으로 확인할 수 있다.
- 적용 뒤 표시 세 가지(버튼의 개수와 검정 테두리, 버튼 줄 아래 값 칩 띠와 ×, 오른쪽 끝 초기화). 무엇이 걸렸는지와 하나씩 빼는 길이 한눈에 있다.
- 모바일에서 누른 필터 알약에 맞는 종류가 열린 채로 시트가 뜨는 것. 원하는 종류까지 다시 찾아 내려가지 않아도 된다.

바꿔서 쓸 것

- 색 이름은 한글로 적는다(BLACK → 검정). 구매 담당자가 견적서에 적을 이름과 같아야 한다.
- 왼쪽 세로 분류 열 대신 가로 알약 탭(`.bh`)을 쓴다. 왼쪽 열을 두면 우리 4열 격자가 좁아진다.
- 모바일 시트는 모든 종류를 이어 붙이지 않고 탭을 누르면 그 종류만 보이게 한다(우리 요구: 한 번에 한 종류).
- 모바일 목록에도 값 칩 줄을 가로 스크롤로 둔다. 이곳은 모바일에서 "컬러 2"만 보이고 어떤 색인지 보려면 시트를 다시 열어야 한다.
- 한 쪽 60개 → 우리는 48개(4열 × 12줄). 쪽 번호에는 이전·다음 화살표를 두고 5개씩 묶는다.

쓰지 않을 것

- "큼페이백" 같은 빨간 테두리 판촉 버튼. 우리는 판촉 필터가 없고 흑백이 기준이다.
- 카드의 좋아요 수·별점 줄. 견적 중심 목록에 넣을 데이터가 없다.
- 모바일 3열. 캡처에서 상품명이 3열 폭에서 두세 줄로 끊긴다. 우리 폰 격자는 2열이다.

## 2. 코오롱몰 — 볼디스트 브랜드관

- 주소: https://www.kolonmall.com/Brands/boldest , https://www.kolonmall.com/Brands/boldest/List/133020161372 ("전체" 목록)

관찰한 사실 — PC

- 브랜드 머리(검정 띠): 로고 + 좋아요 수 + 오른쪽 "볼디스트에서 검색" 입력칸. 그 아래 한 줄 메뉴: 추천·B2B·전체·아우터·베스트·티셔츠/셔츠·팬츠·안전화·용품 | 브랜드 소개·기획전·테크·가이드.

- 목록 위 조작 줄 7단(분류 탭, 컬러, 소재, 기장, 빠른 칩, 필터 버튼, 상품/브랜드/스냅). 모바일 첫 화면의 절반을 쓴다. 우리는 탭 1줄 + 필터 1줄 + 개수·정렬 1줄로 둔다.

## 사용성 근거

1. Baymard, "Display 'Applied Filters' in an Overview" (2026-05-13 고침) — https://baymard.com/blog/how-to-design-applied-filters
   - 벤치마크 사이트의 28%가 적용한 필터 요약을 보여 주지 않는다. 요약은 항상 보여 줘야 한다고 적었다.
   - PC 자리는 세 가지(목록 위, 필터 열 위, 가로 필터 줄 아래)이고 어느 쪽이 낫다는 결과는 없다. 다른 요소에 묻히지 않는 것이 조건이다.
   - 모바일은 목록 위 가로 스크롤 한 줄(오른쪽 끝 칩이 잘려 보이게 해서 더 있음을 알림)이나 여러 줄 쌓기 + "모두 보기"를 권한다.
   - 개수만 보여 주고 값을 숨기지 말 것. 고른 값은 원래 자리에서도 선택 표시를 유지할 것(97%가 그렇게 한다).
2. Baymard, "Allow Applying of Multiple Filter Values" (2024-01-23) — https://baymard.com/blog/allow-applying-of-multiple-filter-values
   - 15%가 한 종류 안에서 여러 값을 고르지 못하게 한다. 사용자는 평균 5~6개 필터를 건다.
   - 같은 종류 안의 값은 "또는", 종류끼리는 "그리고"로 묶는다. 여러 개를 고를 수 있음을 체크박스 모양으로 알린다.
   - 모바일에서 값을 누르는 즉시 적용하면서 요약이 없으면, 하나를 빼려고 필터 화면을 다시 열어야 한다.
3. NN/g, Kathryn Whitenton, "Mobile Faceted Search with a Tray" (2015-07-26) — https://www.nngroup.com/articles/mobile-faceted-search/
   - 필터를 별도 화면으로 보내면 결과와 번갈아 봐야 한다. 결과 위에 겹치는 트레이가 낫다.
   - 결과 수가 계속 보이게 한다. 필터를 여는 곳에는 아이콘보다 "필터" 같은 글자 라벨이 낫다.
4. NN/g, Katie Sherwin, "User Intent Affects Filter Design" (2016-02-07) — https://www.nngroup.com/articles/applying-filters/
   - 결과가 거의 바로 나오면 즉시 적용, 그렇지 않으면 한 번에 적용이 낫다. 모바일은 적용 버튼을 권한다.
   - 필터를 만지는 동안 화면을 맨 위로 옮기지 않는다. 다시 불러오는 동안에는 결과 영역을 흐리게 하고 진행 표시를 둔다.
5. Baymard, "The Number of Products to Load by Default" (2020-01-07) — https://baymard.com/blog/number-of-items-loaded-by-default
   - PC 분류 목록은 한 번에 50~150개(의류처럼 보고 고르는 상품은 100~150개), 모바일은 15~30개를 권한다. 검색 결과는 분류 목록보다 적게. 52%가 이 범위를 벗어난다.
   - 우리 범위(30~48개)에 대입하면 PC에서는 권장 아래쪽, 모바일에서는 권장보다 많다. 그래서 위쪽 값(48개)을 쓰고 폰에서는 그림을 늦게 불러오는 쪽으로 정리했다(아래 문장 7).
6. Baymard, "Search UX: 5 Proven Strategies for Improving 'No Results' Pages" (2025-02-18 고침) — https://baymard.com/blog/no-results-page
   - 약 50%의 사이트가 결과 없음 화면을 막다른 길로 둔다.
   - 넣을 것: 관련 분류 링크, 검색어를 줄인 대체 검색(상품 3~5개 미리 보기), 최근 본 상품, 전화번호·상담 창구(링크 뒤에 숨기지 않음), 인기 상품.
   - 검색 요령 문구만 두는 것은 잘 읽히지 않는다고 적었다.

코오롱몰·무신사의 "N개 상품보기" 일괄 적용은 근거 4와 같은 방향이고, SSF샵·Strauss PC의 즉시 적용은 근거 4에서 결과가 바로 나올 때만 권하는 방식이다. 네파의 "적용 뒤 표시 없음"은 근거 1에 어긋난다.

## 이 유형에 그대로 쓸 수 있는 문장

1. 목록 머리는 경로 → 분류 이름(32px) → 세부 분류 알약 탭 한 줄(맨 앞은 "전체", 넘치면 PC는 줄바꿈·폰은 가로 스크롤) 순서로 두고, 상품 개수는 도구 줄 왼쪽에 "총 128개"로 적어 필터를 걸 때마다 바뀌게 한다.
2. 도구 줄은 PC에서 한 줄이다: 왼쪽에 필터 버튼 6개(소재·형태·색상·사이즈·가격대·시즌, 36px 알약 + 아래 화살표), 오른쪽 끝에 정렬 글자 버튼 3개. 폰에서는 필터 버튼 줄(가로 스크롤)과 개수·정렬 줄을 두 줄로 나눈다.
3. PC에서 필터 버튼을 누르면 그 버튼 아래에 상자가 하나만 뜨고(다른 버튼을 누르면 앞의 상자는 닫힌다), 상자 맨 아래에 "초기화"와 "N개 상품 보기" 버튼을 둔다. 값을 고를 때마다 N이 바뀌고, 이 버튼을 누르기 전에는 목록을 바꾸지 않는다.
4. 모바일 필터는 아래에서 올라오는 시트 하나다: "필터" 제목 + 닫기 → 종류 탭 6개 한 줄 → 고른 값 칩 줄과 "초기화" → 지금 고른 탭 한 종류의 값만 → 맨 아래 고정 "N개 상품 보기"(검정, 전체 폭). 목록에서 누른 필터 버튼의 종류가 열린 채로 시트가 뜬다.
5. 색상 값은 원 견본과 한글 이름을 함께 적는다. PC 상자는 5열(견본 위·이름 아래), 모바일 시트는 2열(견본 왼쪽·이름 오른쪽)이고, 고른 값은 견본 안 체크 + 굵은 이름으로 표시한다. 흰색·아이보리 견본에는 1px 테두리를 둔다.
6. 적용한 필터는 세 군데에 표시한다: 값을 고른 필터 버튼은 검정 테두리 + "색상 2"처럼 개수, 도구 줄 아래 회색 띠에는 값 칩("검정 ×", "남색 ×")과 오른쪽 끝 "초기화", 필터 상자 안에서는 원래 자리의 체크. 칩의 ×를 누르면 그 값만 빠지고, 폰에서는 회색 띠를 가로 스크롤 한 줄로 둔다.
7. 상품 격자는 PC 4열·태블릿 3열·폰 2열, 한 쪽 48개(4열 × 12줄)로 두고 같은 크기 카드만 넣는다(판촉 칸을 섞지 않는다). 쪽 번호는 가운데 정렬 "‹ 1 2 3 4 5 ›"로 5개씩 묶고 현재 쪽은 검정 원이며, 필터나 정렬을 바꾸면 1쪽으로 돌아간다. 폰에서는 화면 밖 그림을 늦게 불러온다.
8. 분류 대표 사진은 머리 아래에 한 장으로 두고 사진 위 왼쪽에 소개 2~3줄을 얹는다. 사진이 여러 장이면 좌우 화살표와 "2 / 8" 쪽 표시를 사진 오른쪽 아래에 둔다. 긴 소개 글은 목록 아래 구역에 두고 사진 위 "소개 더 보기" 버튼으로 내려보낸다.
9. 협력브랜드 목록은 두 단계로 고른다: 첫 줄 브랜드 탭(전체 + 9곳), 브랜드를 고르면 둘째 줄에 형태 탭이 묶음 이름(의류·신발·용품) 뒤에 나뉘어 나온다. 브랜드를 고른 상태에서는 필터 줄에 브랜드 항목을 두지 않는다. 베스트 상품 줄은 격자 위에 제목 + 카드 4개 한 줄(폰은 가로 스크롤)로 둔다.
10. 결과 없음 화면은 검색어를 입력칸에 남긴 채 가운데 두 줄("'○○' 검색 결과가 없습니다." / "검색어를 줄이거나 아래 분류에서 찾아보세요.") → 분류 바로가기 알약 줄 → 견적문의 버튼과 고객센터 전화번호 → 베스트 상품 4개 줄 순서로 둔다. 필터 때문에 0개일 때는 문구 바로 아래에 적용한 값 칩과 "필터 초기화" 버튼을 둔다.
