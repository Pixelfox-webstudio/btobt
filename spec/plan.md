# 하위 페이지 지도

홈을 뺀 40개 페이지를 9개 유형으로 묶었다. 유형마다 대표 페이지 하나를 먼저 완성하고(공용 부품이 이때 정리된다), 같은 유형의 나머지를 그 부품으로 만든다.
상태는 주소 뒤 `?state=키`로 본다. 한 파일에 여러 부분이 있는 페이지는 `?tab=`(고객센터)·`?section=`(마이페이지)·`?cat=`(상품 목록)처럼 원래 주소 값을 함께 쓴다.
실제 상태 목록은 각 페이지 조각(`tools/pages/*.html`) 머리의 `states`가 기준이고, `tools/build.py`가 `spec/pages.json`과 `pages.html`로 옮긴다.

## 페이지가 아닌 공용 부품
- 관심상품 담기·빼기: 상품 카드의 하트 단추와 알림(`js/sub.js`). 상태는 `category.html`에서 본다.
- 방문 기록 동의: 모든 페이지에 뜨는 안내 상자(`js/sub.js`가 넣는다). 상태는 `category.html?state=ck`, `ck-set`.
- 상담 메뉴(고객센터 메뉴 묶음), 헤더의 회원 이름·장바구니 담긴 수·인기 검색어·진행 중 이벤트: 홈 시안에 없는 공통 요소라 `js/sub.js`가 실행 중에 덧붙인다. 홈에도 넣어야 한다.

## 따로 열리는 창(헤더·푸터 없음)
견적서 7종, 시안확인(주문), 견적문의 시안 보기는 요소 목록에 "닫기"가 있는 따로 열리는 창이다. 사이트 헤더·푸터 대신 로고와 닫기만 있는 얇은 머리줄을 쓴다. 근거는 `research/decisions/document.md`.

## 만들지 않는 것
- 홈 시안이 링크하는 `printing.php`, `guide-logo.php`: 요소 목록이 없다. 보고서에만 적는다.
- 요소 목록의 "화면 없는 것" 절: 서버 처리와 예전 주소 넘김이라 화면이 없다.
