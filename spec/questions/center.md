# 질문 기록 — center (고객센터)

결정이 필요했던 곳. 가장 무난한 쪽으로 만들고 한 줄씩 적는다.

- 탭 모양: DESIGN.md 초안 표는 고객센터 탭을 `.bh` 알약 줄로 적었지만, 지침 공용 부품 표가 고객센터 네 부분을 `.stab`으로 정해 `.stab`을 썼다. `.stab`은 11-17 공용 고침으로 tab-pill(알약) 모양이 되어 내 CSS에서 덮어쓴 것은 없다(위 여백만 준다).
- 탭을 바꾸면 공용 `sub.js`가 화면을 맨 위로 올리는데, 고객센터는 메뉴 줄이 머리·상담 띠 아래에 있어 내 JS에서 메뉴 줄 바로 위까지만 올리도록 고쳤다. 다른 페이지도 같은 문제가 있으면 공용 쪽에서 정하는 편이 낫다.
- 회원 1:1 문의를 처음 열면 답변이 달린 최근 문의(A-20261113-0008) 하나를 펼쳐 둔다. 요소 목록은 "누르면 펼쳐짐"만 적었고 처음 상태는 적지 않았다.
- 탭 안 화면 주소: 문의 작성 `?tab=qna&view=write`, 공지 상세 `?tab=notice&id=번호`, 주문방법 종류 `?tab=order-guide&type=noprint`(기본은 값 없음 = 인쇄 있는 주문), 공지 검색·쪽 `&q=…&page=…`. 탭을 바꾸면 다른 탭의 값은 주소에서 지운다.
- 화면 예시 자리 이름: 과제의 `data-slot="guide-이름"`을 파일 이름의 `g-`를 뺀 꼴로 붙였다(예: `g-option-print.webp` → `data-slot="guide-option-print"`). 같은 그림이 두 안내에 나오면 같은 자리 이름을 쓴다.
- 화면 예시 임시 그림(`img/guide/*`)은 홈·목록 화면을 자른 것이라 안에 AI 연출 사진 일부가 보인다. 실제 시안 화면으로 바뀔 그림이라 `data-temp="ai"`와 "연출 이미지입니다."는 붙이지 않았다.
- 주문방법 5단계의 단계 제목은 요소 목록 문장을 행동 이름으로 줄였다(예: "상품 옵션·수량 고르기", "시안·견적서 확인하고 승인하기"). 5단계 결제 진행의 도입 문장 "견적 금액이 정해진 주문은 주문 내역에서 결제를 진행"은 주문서 절 L378(관리자가 견적 금액을 넣은 요청을 결제진행에서 결제)에서 가져왔다.
- 주문방법 결제 안내의 후불결제 예외("인쇄 없는 할인 견적 기반 요청은 예외")와 세금계산서 발송처("담당자 이메일, 없으면 주문자 이메일")는 주문서 절 L393~L394 문장을 썼다.
- 자주 묻는 질문 14개·공지 21건·문의 글은 견본(`data-sample`)이다. 내용은 요소 목록과 지침 7.4에 있는 사실(결제수단, 후불결제 대상, 세금계산서, 수량 할인, 제작 기간, 견적서 유효기간, 사이즈 오차, 교환·환불)만 썼고, 날짜·기간이 걸린 새 공지(연휴 배송 일정 등)는 만들지 않았다.
- 1:1 문의 상태의 "그 밖의 상태"는 견본으로 "처리중" 한 건을 회색 칩으로 넣었다. 실제 상태 이름은 운영 값으로 바뀐다.
- 방금 접수한 문의번호: 회원 `A-20261117-0012`, 비회원 `A-20261117-0013`(오늘 날짜). 지침 7.4의 `A-20261113-0008`은 목록의 기존 답변완료 문의로 썼다.
- 비회원 견본 문의자: 지침 7.4에 비회원 값이 없어 "정하늘 · 010-3456-7890"을 새로 썼다(`data-sample`).
- 회원 문의 조회 기간의 기본값은 요소 목록에 없어 "3개월"을 눌린 상태로 두었다(날짜 칸은 2026-08-19 ~ 2026-11-17).
- 관리자 답변 첨부(존재 여부 불확실, L1660·L1683)는 답변 한 건에만 PDF 한 개를 견본으로 붙였다.
- 공지 구분 칸: 중요 공지는 검정 "중요" 칩, 나머지는 "일반" 글자로 적었다(요소 목록 "구분(중요 공지 / 일반)").
- 없는 공지 번호로 들어오면(L1775) 목록을 대신 보이면서 "찾는 공지가 없거나 내려간 공지입니다" 한 줄을 위에 둔다. 요소 목록에는 목록만 적혀 있어 안내 한 줄은 덧붙인 것이다.
- 회원 상태가 유효하지 않을 때(L1582)는 서버가 로그아웃 후 로그인으로 보내는 동작이다. 시안에서는 `?state=guest+expired`로 로그아웃 상태 + "회원 정보를 확인할 수 없어 로그아웃했습니다" 안내와 로그인 버튼을 보여 준다(실제로 이동시키면 상태를 볼 수 없다).
- 비회원 조회는 서버가 없어 이름·비밀번호를 넣으면 늘 견본 결과 2건이 열린다. 불일치·시도 초과·문의 없음은 상태 키로 본다.
- 폰에서 주문방법 단계는 한 번에 한 단계만 연다(처음 1단계). PC(1024 이상)에서는 왼쪽 목록에서 고른 단계 하나가 오른쪽에 늘 열려 있다.
