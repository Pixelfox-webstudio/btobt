# 질문 기록 — auth (로그인·회원가입)

결정이 필요했던 곳과 고른 답. 한 줄씩.

- 기업 회원 승인: 요소 목록 L1182는 "가입 즉시 이용 가능(관리자 승인 절차 없음)"인데 홈 위 띠(index.html)는 "사업자등록증 확인 후 기업회원 승인"이다. → 요소 목록대로 "관리자 승인 없이 바로 이용"으로 썼다. 홈 띠 문구를 바꿀지 사장님 확인이 필요하다.
- 약관 동의: 요소 목록의 정보 입력 묶음은 개인정보 / 회사정보(주소정보) / 광고성 정보 수신 동의 / 자동등록방지뿐이라 이용약관·개인정보 수집 동의 체크를 넣지 않았다. 실제 가입에는 필수 동의가 필요할 수 있다.
- 아이디·비밀번호 찾기: 기능이 있는지 정해지지 않아(L1022) 팝업 안내(고객센터 번호·상담 시간·카카오톡 상담)로 두었다. 찾기 기능을 만들면 그 화면으로 바꾼다.
- 간편 가입 회원의 아이디·비밀번호: L1038(간편 가입은 비밀번호 없음)에 맞춰 간편 가입 중에는 비밀번호 두 칸을 감추고 "가입 뒤 마이페이지에서 정할 수 있습니다"를 적었다(마이페이지 상태 "비밀번호 설정(간편 가입)"과 짝). 아이디 칸은 남겼다.
- 가입 단계 수: 가입 방법 선택은 "2단계 중", 정보 입력은 "3단계 중"이라 요소 목록 그대로 방법 선택에는 2칸(회원 유형 → 가입 방법), 정보 입력에는 3칸(… → 정보 입력)을 두었다.
- 처음 간편 로그인한 사람(L1039): 회원 유형을 먼저 고르게 하고(회원가입 화면에 "카카오 계정을 확인했습니다" 안내) 고른 유형의 정보 입력(간편 가입 중 상태)으로 이었다.
- 회원 유형 선택의 "가입하기"와 "이메일로 계속하기": 가입하기는 가입 방법 선택으로, 이메일로 계속하기는 정보 입력(직접 입력)으로 바로 가게 했다. 간편 가입 3개는 같은 화면에서 바로 정보 입력(간편 가입 중)으로 간다.
- 회사 주소: 기업 회원의 우편번호·주소·상세주소를 회사정보 묶음 안에 "회사 주소"로 두었다.
- 기업 정보 입력 순서: 회사정보를 개인정보보다 먼저 두었다(사업자등록번호 확인을 계정 정보보다 먼저). 요소 목록에 적힌 묶음 순서와 다르다.
- 사업자등록번호 확인: 번호 규칙(검증 숫자) 검사로 만들었다. 견본 번호 123-45-67890은 실제 규칙에는 맞지 않아 시안에서만 통과시킨다.
- 로그인 시도 초과·자동등록방지 시도 제한: 몇 번·몇 분인지 정해지지 않아 숫자 없이 "잠시 뒤에" / "여러 번 틀리면 잠시 입력할 수 없습니다"로 적었다.
- 간편 로그인 실패 4가지(설정 미완료·보안 검증 실패·취소·기타)는 상태 4개로 나눠 각각 문구를 두었다.
- 가입 완료 뒤 이동: 보던 페이지가 없으면 [메인화면으로]와 [로그인](직접 입력은 자동 로그인 안 됨), 보던 페이지가 있으면 직접 입력은 [로그인하고 이어 보기], 간편 가입은 로그인된 채 [장바구니로 이동]을 두었다. 시안이라 자동으로 넘어가지는 않는다.
- 로그인 "이미 로그인" 화면: `spec/plan.md` 로그인 줄에는 없지만 요소 목록 L1030과 과제 설명에 따라 `?state=member` 상태로 두었다(실제로는 화면 없이 넘어가는 동작이라 시안에서는 넘어갈 곳을 알리는 결과 화면으로 보인다).
- 정보 입력의 오류 상태를 셋으로 나눴다: 빠진 항목(`err`) / 확인 실패(`bad`: 중복확인 연결 오류·무효 번호·용량 초과·숫자 불일치) / 이미 가입·사용 중(`dup`). `plan.md`의 "입력 오류" 하나로는 요소 목록 안내를 한 화면에 다 보일 수 없어서다.
- 자동등록방지 만료(L1135 "불일치·만료"): 숫자 그림의 유효 시간·잠금 횟수·잠금 시간이 정해지지 않았다. 상태 `capexp`(그림 만료)·`caplock`(시도 초과)을 따로 두고 화면에는 숫자 없이 적었다. 시안 동작은 10분 지나면 만료, 5번 틀리면 30초 잠금(코드 안의 임시 값).
- 단계 표시·필수 *·확인 문구의 파랑과 Barlow 번호는 공용 부품(`00-base.css` `.stp`, `10-form.css` `.fld__l em` · `.fld__msg--ok` · `.fld__l small`)의 값이다. 검수 지적에 따라 내 조각(`60-auth.css` 3절)에서 이 여섯 페이지에만 덮어썼다. 공용 쪽에 반영할지 반장 확인이 필요하다.
