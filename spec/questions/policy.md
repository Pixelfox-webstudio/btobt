# 질문 기록 — policy (약관·정책 문서 4종)

- 약관 묶음 메뉴: 과제는 `nav.stab` 마크업을 정했지만, 검수 지적(밑줄 탭 → 알약, 폰에서 탭 글자가 반쯤 잘림)에 따라 필터칩 묶음(`nav.fchips` > `a.fchip[aria-current]`)으로 바꿨다. 링크·`aria-label`·`aria-current`는 과제 그대로다. 공용 `.stab`은 지금 알약 줄로 바뀌었지만 폰에서 옆으로 넘기는 한 줄이라 네 문서 이름이 다 보이지 않아 칩 묶음(폰 두 줄)을 유지했다. 다른 하위 페이지의 알약 탭 줄과 모양을 맞추고 싶다면 폰에서 줄바꿈되는 `.stab` 변형이 공용에 필요하다.
- 폰에서 개인정보처리방침의 긴 표 네 개(수집 항목·쿠키·보관 기간·구제 기관)를 접고 요약 한 줄만 보이게 했다(PC·태블릿·인쇄는 펼침). 법정 고지 문서에서 표를 접어 두는 것이 괜찮은지 법무 확인이 필요하면 알려 주세요. 네 표를 모두 펼치면 390 폭 화면이 6,752px에서 9,499px로 늘어난다.
- 이전 방침은 요소 목록대로 "운영자가 입력한 글 하나"로 보고, 버전 선택 상자 대신 제목 아래 `이전 방침 보기` 링크 하나와 13번 항목 아래 버튼으로 두었다. 이전 방침이 여러 개 쌓이는 구조라면 목록(시행일별)이 필요하다.
- 운영자가 입력한 글(이용약관, 취소/환불 정책, 직접 쓴 방침, 이전 방침)은 편집기에서 서식(조 제목 굵게, 목록, 표)을 넣을 수 있다고 보고 그렸다. 줄바꿈만 있는 글자 입력이라면 조 제목 굵기·표는 빠지고 줄바꿈만 살려 보인다.
- 쿠키·저장 이름(`PHPSESSID`, `b2bt-consent`, `b2bt-recent`, `b2bt-keep`, `b2bt-visit`, `b2bt-ux`, `b2bt-ad`)과 방문 통계·화면 이용 기록·광고 효과 측정 쿠키의 보관 기간("동의한 날부터 1년")은 견본(`data-sample`)이다. 실제 이름과 기간은 개발에서 받아 채워야 한다. 요소 목록에 있는 값(동의 선택 1년 유지, 로그인 전 고른 값 30분)만 확정 값으로 썼다.
- 처리 위탁 업체: 카드 결제 대행사는 시안 파일 이름(nicepay-return)에서 나이스페이먼츠로 보고 견본으로 적었다. 배송은 "주문 때 고른 배송 업체"로 두었다. 문자·메일 발송 대행처럼 다른 위탁이 있으면 알려 주세요. 제3자 제공·국외 이전은 "해당 없음"(견본)으로 두었다.
- 개인정보 보호책임자는 푸터의 "개인정보담당자 : 고도혁"과 "대표이사 : 고도혁"을 합쳐 "고도혁 (대표이사)"로 적었다. 담당 부서가 따로 있으면 줄을 더한다.
- 비회원 방침의 회사소개 사이트 견적 문의·샘플 신청·협력업체 신청의 받는 항목(이름·회사명·연락처·이메일·주소)은 요소 목록에 없어 견본으로 적었다. 회사소개 사이트 양식의 실제 항목으로 바꿔야 한다.
- 비회원 방침 시행일은 "설정된 시행일"이 있는 경우만 그렸다. 시행일이 없을 때의 문구("고쳐 쓴 날과 게시일부터 적용")는 상태로 따로 만들지 않았다. 필요하면 상태 하나를 더한다.
- 비회원 방침의 목차(L504)는 요소 목록에 "현재 해당 없음"이라 두지 않았고, 요소 점검 보조표에 `na`로 적었다.
- 이용약관·취소/환불 정책 본문의 조항(약관 개정 공지 7일·30일, 청약 철회 기간 7일, 불량 3개월·30일, 환불 3영업일)은 관련 법령·표준약관의 기간을 견본으로 쓴 것이다. 회사가 정한 배송비 금액·반품 주소는 없어서 적지 않았다. 실제 약관 문구는 회사가 확정해야 한다.
