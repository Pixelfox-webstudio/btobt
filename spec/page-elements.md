## 사이트 전체 공통 요소
어느 페이지에서나 쓰는 이동·검색·회원·상담·회사 정보 요소.

### 보여 주는 정보
- 사이트 로고(홈으로 이동)
- 소식 안내 여러 건(이전·다음 소식 보기 가능)
  - 핵심 혜택 안내(공장 직납·후불 결제·기업·관공서 전용 맞춤작업복)
  - 회사소개 사이트 안내(회사소개 사이트로 이동, 새 창)
  - 카카오톡 채널 상담 시 견적 추가 할인 안내(카카오톡 채널로 이동, 새 창)
  - 빠른 견적 요청 안내(견적문의로 이동)
- 카테고리 메뉴
  - 단체복: 분류별 세부 분류와 세부 분류별 상품 수, 단체복 전체보기
  - 작업복: 봄·여름·가을·겨울 작업복, 작업복 전체보기
  - 협력브랜드: 브랜드 로고(로고 없으면 이름)와 브랜드별 상품 수, 협력브랜드 전체보기
  - 맞춤작업복: 맞춤작업복 견적문의
- 서비스 메뉴: 단체복 전체보기·주문방법·인쇄방법·납품사례·구매후기·이벤트·파트너십
- 바로가기 메뉴: 견적문의·시안확인·회사소개(새 창)·고객센터·주문내역·공지사항·1:1 문의
- 로그인 회원 이름(마이페이지로 이동)
- 장바구니 담긴 수(1건 이상일 때, 로그인 회원 기준)
- 고객센터 정보: 대표 전화(전화 연결), 평일 운영시간(휴게시간·주말·공휴일 제외), 이메일 주소
- SNS 바로가기: 인스타그램·카카오톡 채널·네이버 블로그·유튜브(모두 새 창)
- 고객센터 메뉴 묶음
  - 마스코트 그림
  - 빠른 이동: 견적문의·시안확인·주문방법·카카오톡 상담
  - 이동: 주문내역·견적문의 내역·시안확인·배송조회·관심상품·고객센터
  - 대표 전화·운영시간·이메일
  - 입금계좌 확인(값이 있을 때만)
  - 맞춤작업복 안내(맞춤작업복으로 이동)
  - SNS 바로가기
- 정책 안내 이동: 이용약관·개인정보처리방침·방문 기록 설정·FAQ·취소/환불 정책·공지사항
- 사업부별 주소·전화번호(부산·경남·온라인·물류사업부, 전화 연결)
- 회사 정보: 상호·대표이사·개인정보담당자·사업자등록번호·통신판매번호·대표전화(전화 연결)·이메일(값 있을 때만)
- 입금계좌 정보(은행·계좌번호·예금주가 모두 있을 때만): 입금계좌와 통장 사본 이미지
- 인증·거래처 로고: 공정거래위원회·국방전자조달시스템·나라빌·학교장터·조달청·서울보증
- 저작권 표시

### 입력·선택
- 상품 검색어 입력(선택 입력, 최대 100자, 지금 검색어가 들어 있음)
- 방문 기록(쿠키) 동의 선택: 거부 / 동의 / 항목별 설정
  - 항목별 설정: 방문 통계·화면 이용 기록·광고 효과 측정 중 선택(여러 개 가능, 항목마다 설명, 보이는 항목은 운영 설정에 따름), 선택 저장

### 할 수 있는 일
- 상품 검색(검색 결과로 이동)
- 최근 검색어 보기·다시 검색·하나씩 삭제·전체 삭제(최근 10개, 이 기기에만 저장)
- 인기 검색어 보기(최근 30일 실제 검색 중 결과가 있던 검색어, 순번 포함; 기록이 없으면 분류 이름을 추천 검색어로)
- 진행 중 이벤트 보기(최대 4건: 이미지·이벤트 표시·제목, 이벤트 상세로 이동); 이벤트가 없으면 대표 분류 3개(사진·분류 목록으로 이동)
- 전체 메뉴 보기·닫기(지금 보고 있는 페이지의 분류가 처음부터 선택됨, 지금 페이지 표시)
- 사업 바로가기: 단체복·작업복·협력브랜드·맞춤작업복(지금 페이지 표시)
- 견적문의로 이동(견적문의 소개 화면에서는 견적문의 작성으로, 맞춤작업복 소개 화면에서는 맞춤작업복 문의 양식으로)
- 시안확인으로 이동(마이페이지 시안확인)
- 회사소개 사이트로 이동(새 창)
- 로그인 / 로그아웃
- 회원가입으로 이동(비로그인)
- 마이페이지로 이동(비로그인이면 로그인으로)
- 장바구니로 이동(비로그인이면 로그인으로)
- 주문방법·고객센터·주문내역·공지사항·1:1 문의로 이동
- 빠른 상담: 견적문의 / 전화상담 / 채팅상담(채팅 상담 서비스가 켜져 있으면 그 메신저, 아니면 카카오톡 채널)
- 카카오톡 상담(카카오톡 채널, 새 창)
- 전화상담(대표 전화 연결)
- 채팅 상담 서비스 이용
- 입금계좌 확인 보기·닫기
- 방문 기록 설정 다시 보기
- 개인정보처리방침 보기(방문 기록 안내에서)
- 페이지 처음으로 돌아가기(한 화면 넘게 내려갔을 때만)
- 관심상품 담기·빼기(로그인 회원만, 같은 상품 표시가 모두 함께 바뀜)

### 안내·상태
- 최근 검색어 없음 안내
- 인기 검색어 자료가 없으면 인기 검색어 생략
- 상담 시간 외 안내(채팅상담 우선, 전화상담 운영시간 표시)
- 글 입력 중에는 빠른 상담 감춤
- 주문서·바로주문·주문 완료 화면에서는 빠른 상담 없음
- 방문 기록(쿠키) 안내: 무엇을 남기는지, 이름·연락처는 담지 않음, 거부해도 이용 제한 없음(아직 고르지 않은 방문자에게만)
- 관심상품 비로그인 안내 후 로그인으로 이동(로그인 뒤 원래 화면으로)
- 관심상품 처리 실패 안내
- 이미지 불러오는 중 표시
- 상품 사진 끌어 옮기기 막음(저장은 허용)

## 단체복·작업복 상품 목록
단체복 분류와 작업복의 상품을 세부 분류·필터·정렬로 골라 보는 페이지.

### 보여 주는 정보
- 분류 이름(페이지 제목, 작업복은 화면 낭독용 제목도 있음)
- 세부 분류 목록(세부 분류가 있을 때만): 전체보기 + 세부 분류들, 지금 세부 분류 표시
  - 라운드 티셔츠 일부 세부 분류는 알기 쉬운 이름으로 표시(반팔·긴팔, 아동용 티셔츠)
  - 작업복은 봄·여름·가을·겨울 순
- 분류 대표 사진과 소개 글(머리글·제목·설명, 분류별; 소개가 없는 분류는 공통 소개)
  - 사진이 여러 장인 분류(라운드 티셔츠·작업복): 이전·다음 보기(끝없이 돎), 끌어서 넘기기, 진행 정도 표시
- 견적 문의하기(견적문의로 이동)
- 베스트 상품(작업복만, 최대 8개: 베스트 지정 상품 중 임의로, 모자라면 같은 분류의 다른 상품으로 채움)
- 상품 수(필터 적용 후)
- 적용한 필터 개수(있을 때)
- 상품 목록(한 쪽에 48개)
  - 항목마다: 상품 사진(옷만 찍은 앞면 사진이 있으면 그것, 마우스를 올리면 다른 사진, 상품 상세로 이동) / 상품명(상품 상세로 이동) / 가장 작은~가장 큰 사이즈(하나면 그 값) / 색상 견본(최대 5개, 넘으면 나머지 개수; 사이즈·색상 둘 다 없으면 생략) / 가격(가격대 이름, 없으면 판매가, 판매가가 없으면 견적문의) / 관심상품 담기·빼기(이미 담았으면 담김 표시) / 장바구니 바로가기(상품 상세로 이동, 바로 담지 않음)
- 쪽 번호(5개 묶음, 지금 쪽 표시, 처음·이전 묶음·다음 묶음·마지막 이동; 쪽이 하나면 없음)

### 입력·선택
- 정렬 선택(하나): 추천순(기본)·신상품순·판매량순
- 필터 선택(여러 개 가능, 한 번에 한 종류만): 소재·형태·색상(색 견본 + 이름)·사이즈·가격대·시즌
  - 선택지는 이 분류 상품이 실제로 가진 값만(이미 고른 값 포함)

### 할 수 있는 일
- 세부 분류 바꾸기
- 정렬 바꾸기(첫 쪽으로)
- 필터 보기·닫기
- 필터 묶음 펼치기
- 필터 초기화
- 필터 적용(완료)
- 쪽 이동
- 상품 상세로 이동
- 관심상품 담기·빼기
- 견적문의로 이동

### 안내·상태
- 베스트 상품 없음 안내(작업복)
- 조건에 맞는 상품 없음 안내

## 검색 결과
검색어로 찾은 상품을 필터·정렬해 보는 페이지(검색어가 없으면 전체 상품).

### 보여 주는 정보
- 지금 경로 표시: 홈 · 검색
- 제목: 검색어의 검색 결과(검색어 없으면 전체 상품, 화면 낭독용 제목 포함)
- 상품 수(쉼표 구분)
- 적용한 필터 목록(필터가 있을 때만): 값마다 표시(색상은 색 견본 포함)
- 필터 묶음별 적용 여부 표시
- 상품 목록(한 쪽에 30개)
  - 항목마다: 상품 사진 / 상품명 / 사이즈 / 색상 견본 / 가격 / 관심상품 담기·빼기 / 장바구니 바로가기(단체복·작업복 상품 목록과 같은 구성)
- 쪽 번호(5개 묶음)

### 입력·선택
- 검색어(공통 상품 검색에 지금 검색어가 들어 있음)
- 정렬 선택(하나): 추천순·신상품순·판매량순
- 필터 선택(여러 개 가능): 소재·형태·색상(색 견본 + 이름)·사이즈·가격대·시즌
  - 선택지는 이 검색 결과 상품이 실제로 가진 값만
  - 필터 모음 보기에서는 한 번에 한 종류만

### 할 수 있는 일
- 필터 묶음 펼치기, 묶음별 초기화·적용(첫 쪽으로)
- 필터 모음 보기·닫기(필터 묶음별 바로 이동 포함), 전체 초기화·완료
- 적용한 필터 값 하나씩 빼기
- 적용한 필터 전부 빼기(검색어·정렬은 유지)
- 정렬 바꾸기
- 쪽 이동
- 상품 상세로 이동
- 관심상품 담기·빼기
- 견적문의로 이동(결과 없을 때)
- 이 페이지를 보면 최근 검색어에 저장

### 안내·상태
- 검색 결과 없음 안내 + 견적문의로 이동
- 검색 규칙: 검색어를 낱말(최대 10개)로 나눠 모두 포함하는 상품, 상품명·상품코드·분류명·큰 분류명 대상, 띄어쓰기·일부 기호·대소문자 무시
- 검색엔진 노출 제외

## 상품 상세
상품의 옵션·색상·사이즈별 수량·포장·인쇄를 골라 주문 요청하거나 장바구니에 담는 페이지. 협력브랜드 상품이면 일부가 달라짐.

### 보여 주는 정보
- 지금 경로 표시: 홈 · (협력브랜드 상품이면 협력브랜드) · 큰 분류(협력브랜드 상품은 브랜드명) · 작은 분류(각각 해당 목록으로 이동)
- 상품 사진 여러 장(대표 사진·추가 사진·상세 갤러리 사진, 중복 제외)
  - 사진이 없으면 빈 사진 표시
  - 2장 이상이면: 이전·다음 보기(끝없이 돎), 몇 번째 사진인지 표시, 원하는 장으로 이동, 손가락으로 넘기기
- 상품명
- 소재·시즌(값 있는 것만)
- 제작 소요 기간 안내(협력브랜드 상품 아니면), 유의사항·배송/포장안내로 이동
- 선택 단계별 완료 표시와 진행 정도
- 총수량(벌)
- 총액(판매가가 있으면 수량 할인 적용 금액: 10벌 이상 5%·30벌 이상 10%·50벌 이상 15%; 판매가가 없으면 견적문의)
- 대량 주문·맞춤 제작 상담 안내: 대표 전화(전화 연결), 카카오톡 상담하기(카카오톡 채널, 새 창)
- 상세 정보: 상품정보 / 배송/포장안내 / 반품/교환안내 / 유의사항(각 부분으로 이동, 지금 보고 있는 부분 표시)
  - 상품정보 이미지(상품별, 없으면 공통)
  - 배송/포장안내 이미지(공통)
  - 반품/교환안내 이미지(공통)
  - 유의사항(제작 소요 기간)
- 구매 부분이 화면을 벗어나면 따로 계속 제공: 총수량·진행 정도·전화 상담·카카오톡 상담·주문하기(협력브랜드 상품은 견적문의)·장바구니

### 입력·선택
- 상품 옵션 1~5(값이 2개 이상인 옵션만, 옵션마다 하나 선택, 필수)
- 색상 선택(색상 있는 상품만, 여러 색 함께 선택 가능, 색 견본 + 이름; 견본은 상품별 실제 색 데이터 우선)
  - 고른 색을 다시 고르면: 수량이 0이면 빼고, 수량이 있으면 그 색의 수량 입력을 강조
- 사이즈별 수량 입력(필수)
  - 색상 있는 상품: 색상마다 사이즈별 수량, 색상별 소계(벌), 색상 빼기(처음엔 첫 색상 하나)
  - 색상 없는 상품: 사이즈별 수량 하나(사이즈가 없으면 기본 하나)
  - 수량 빼기·더하기(길게 누르면 연속), 직접 입력(비우면 0)
  - 협력브랜드 상품에 등록 사이즈·색상이 없으면: 사이즈별 수량을 글로 적기(최대 500자, 모델이 여러 개면 모델번호별로), 적은 벌수를 더해 총수량에 반영
- 포장 방식 선택(하나, 첫 항목 기본; 협력브랜드 상품 아니면)
- 인쇄 여부 선택(하나: 인쇄 없음 기본 / 인쇄 있음; 인쇄 가능 상품만; 협력브랜드 상품은 인쇄 있음이면 상담 후 결정)
- 인쇄 상세(인쇄 있음이고 협력브랜드 상품 아닐 때)
  - 인쇄방법 선택(하나, 필수)
  - 인쇄 부분 안내 그림(상품별, 없으면 분류별 기본 그림)
  - 인쇄 부분 선택(여러 개 가능, 필수)
  - 인쇄 설명(인쇄 내용·색상·요청사항, 선택)
  - 인쇄 파일 첨부(선택, 최대 10개·파일당 10MB·합계 100MB, 이미지·PDF·AI·PSD·EPS·ZIP): 첨부 개수 표시, 미리보기(이미지가 아니면 파일 형식과 이름), 하나씩 삭제

### 할 수 있는 일
- 관심상품 담기·빼기(비로그인이면 고른 값을 보관하고 로그인으로)
- 주문하기(협력브랜드 상품은 견적문의, 로그인 회원만): 필수 확인 → 고른 색상마다 장바구니에 담고 주문 요청 → 주문내역으로 이동, 진행 중 표시
- 장바구니 담기(로그인 회원만): 필수 확인 → 색상마다 한 건 → 장바구니 담긴 수 갱신 → 담은 내용(상품·색상·수량) 확인 후 장바구니로 이동할지 선택
- 비로그인 주문·장바구니 시 고른 값(옵션·색상·수량·포장·인쇄·설명·파일)을 30분 보관하고 로그인 뒤 되살림
- 전화 상담, 카카오톡 상담
- 상세 정보 각 부분으로 이동
- 쇼핑 계속하기(상품이 없을 때, 홈으로)

### 안내·상태
- 상품 없음 안내(판매 종료·없는 상품)
- 상품 옵션 미선택 안내
- 색상을 먼저 고르라는 안내(고른 색상이 없을 때)
- 수량 미입력 안내(글로 적는 경우 벌수와 함께 적으라는 안내)
- 포장 미선택 안내
- 인쇄방법 미선택 안내
- 인쇄 부분 미선택 안내
- 포장 옵션 없음 안내
- 인쇄 불가 상품 안내
- 등록된 인쇄방법 없음 안내
- 등록된 인쇄 부분 없음 안내
- 첨부 파일 용량 초과 안내(파일당·합계)
- 같은 파일 중복 첨부 안내
- 주문·장바구니 비로그인 안내
- 주문·장바구니 실패 안내
- 로그인 뒤 파일 일부가 되살아나지 않으면 인쇄 파일 첨부로 이동해 강조
- 상품정보 없음 안내
- 배송/포장안내 없음 안내
- 반품/교환안내 없음 안내

# 요소 목록 2 — 장바구니·주문·결제

## 장바구니
로그인 회원이 담은 상품을 확인·수량 수정·삭제하고, 고른 상품을 견적·시안 요청으로 접수한다.

### 보여 주는 정보
- 담긴 상품 목록(상품마다 다음 정보)
  - 상품 사진(없으면 대체 그림)
  - 상품명
  - 색상
  - 인쇄 여부(있음/없음)
  - 포장 방식
  - 사이즈별 수량
  - 총 수량
  - 금액(단가 × 수량, 단가가 없는 상품은 견적문의로 표시)
- 주문 요약
  - 선택한 상품 목록(상품명·총 수량·금액)
  - 선택한 상품의 총 수량
- 상품 정보 자세히 보기(상품명을 고르면)
  - 상품 사진(없으면 대체 그림)·상품명
  - 상품 옵션
  - 색상
  - 사이즈
  - 사이즈별 수량
  - 포장
  - 인쇄 여부
  - 인쇄 상품이면: 인쇄 방법 / 인쇄 부위 / 인쇄 설명 / 첨부파일(파일명·용량)
- 장바구니 담긴 수(사이트 공통 표시를 이 페이지 내용으로 갱신)

### 입력·선택
- 상품별 선택(여러 개 가능, 처음 들어오면 전부 선택됨)
- 전체 선택/해제(일부만 선택된 상태도 구분)
- 사이즈별 수량 수정(0 이상, 모든 사이즈 합이 0이면 그 상품 삭제)

### 할 수 있는 일
- 선택 삭제(첨부파일 함께 삭제, 처음 들어와 선택을 한 번 바꾸기 전에는 쓸 수 없음 — 실수로 전체 삭제 방지)
- 상품 하나 삭제(첨부파일 함께 삭제)
- 상품 정보 자세히 보기 / 닫기
- 첨부파일 내려받기
- 주문하기(선택한 상품을 견적 요청으로 접수, 인쇄 상품이 하나라도 있으면 시안 확인을 겸한 주문 요청) → 주문 완료로 이동
- 쇼핑 계속하기 → 메인으로 이동

### 안내·상태
- 로그인 회원만(비로그인은 로그인으로 이동)
- 빈 장바구니 안내 + 쇼핑 계속하기(이때 선택·주문 요약 없음)
- 주문할 상품 미선택 안내
- 삭제할 상품 미선택 안내
- 장바구니 처리 실패 안내
- 주문 요청 저장 실패 안내
- 상품이 있을 때는 사이트 공통 상담 연결 요소를 감춤

## 주문 정보 입력 후 접수
장바구니 상품에 주문자·배송 정보를 미리 적어 견적·시안 요청으로 접수한다. 장바구니 상품을 지정해 직접 들어오는 페이지(다른 페이지에서 연결 없음).

### 보여 주는 정보
- 주문 상품 목록(수정 불가)
  - 상품 사진
  - 상품명
  - 색상 / 인쇄 여부 / 포장 방식
  - 사이즈별 수량
  - 총 수량
  - 금액 또는 견적문의
- 상품 정보 자세히 보기(장바구니와 같은 내용: 상품 옵션·색상·사이즈·수량·포장·인쇄 여부, 인쇄 상품이면 인쇄 방법·인쇄 부위·인쇄 설명·첨부파일)
- 주문 요약
  - 상품금액(견적문의)
  - 배송비(견적서에 포함)
  - 총 결제금액(상담 후 결정)
- 희망배송일 확인 사항 안내(인쇄 없는 상품 3~4일, 인쇄 상품 4~7일 등 제작 기간)
- 납품사례 활용 안내(활용 목적 / 게시 장소 및 게시 내용 / 게시물 관리 및 삭제 요청)
- 장바구니 담긴 수(사이트 공통 표시 갱신)

### 입력·선택
- 견적정보
  - 고객 견적서 파일 첨부(선택, 1개, 20MB 이하, 이미지·PDF·문서·엑셀·한글·압축 파일)
- 주문정보(회원정보로 미리 채움)
  - 주문하시는 분(필수)
  - 주소(필수): 우편번호 / 주소 / 상세주소, 우편번호 검색
  - 휴대전화(필수, 중요한 알림이 문자로 간다는 안내)
  - 연락처 2(선택)
  - 이메일(필수, 주문 처리 과정이 메일로 간다는 안내)
- 배송정보
  - 배송지 지정 방식 선택(하나): 주문자와 동일(주문정보 복사) / 대표주소(기본 배송지 적용) / 새로운 배송지(비우고 새로 입력)
  - 받으시는 분(필수)
  - 배송지(필수): 우편번호 / 주소 / 상세주소, 우편번호 검색
  - 연락처 1(필수)
  - 연락처 2(선택)
  - 희망배송일(날짜, 선택)
  - 배송방법 선택(하나, 기본은 기본배송/택배): 기본배송/택배 / 퀵서비스(서울·경기) / 고속버스화물(지방) / 방문수령(픽업장소 협의). 방문수령 외에는 배송비가 견적서에 포함된다는 설명
  - 배송메세지(자유 입력, 선택)
  - 납품사례 활용 동의 여부(필수, 동의 / 동의하지 않음 중 하나)

### 할 수 있는 일
- 상품 삭제(삭제 후 메인으로 이동)
- 상품 정보 자세히 보기 / 닫기
- 첨부파일 내려받기
- 주문하기(인쇄 상품이 있으면 시안 확인을 겸한 주문 요청) → 접수 후 마이페이지로 이동

### 안내·상태
- 로그인 회원만(비로그인은 로그인으로 이동)
- 지정한 상품이 없거나 내 장바구니 상품이 아니면 장바구니로 이동
- 대표주소 없음 안내(배송지 관리에서 등록하라는 안내)
- 주소 검색 서비스 불러오기 실패 안내
- 접수할 상품 미선택 안내
- 필수 항목 미입력 안내(항목별)
- 납품사례 활용 동의 미선택 안내
- 접수 완료 안내(마이페이지에서 주문내역·시안 확인 가능)
- 접수 실패 안내
- 견적서 파일이 용량·형식 조건에 맞지 않으면 저장되지 않음

## 주문서 작성(결제)
관리자가 견적 금액을 넣은 요청, 또는 후불결제 건의 잔금을 회원이 결제한다. 마이페이지 주문내역의 결제진행에서 들어온다.

### 보여 주는 정보
- 주문 상품 목록(견적서 항목 기준, 없으면 원 요청 상품, 수정 불가)
  - 상품 사진(없으면 대체 그림)
  - 상품명
  - 색상 / 인쇄 여부 / 포장 방식
  - 사이즈별 수량
  - 총 수량
  - 금액(단가 × 수량, 단가 없으면 견적문의)
- 견적정보
  - 요청번호
  - 최종 견적금액
- 보유 포인트
- 주문시 유의사항
  - 후불결제 안내(관공서·공공기관·학교만 이용 가능, 인쇄 없는 할인 견적 기반 요청은 예외)
  - 세금계산서 안내(무통장입금 결제 시에만 발행, 결제 확인 후 영업일 1~3일 내 담당자 이메일로 발송·미기재 시 주문자 이메일, 선발행·날짜 지정은 전화 요청, 누락 시 입금일 기준 다음 달 10일까지 추가 신청 가능)
- 희망배송일 안내 사항(희망배송일은 참고용, 인쇄 미적용 3~4일·인쇄 적용 4~7일(주말 제외), 정해진 날짜까지의 납품 관련 안내)
- 총 결제금액 요약
  - 총 상품금액(견적 금액)
  - 배송비(견적서에 포함)
  - 포인트 사용액
  - 총 결제금액(상품금액 − 포인트)
- 잔금 결제일 때: 주문정보·배송정보가 원 주문 정보이며 수정 불가라는 표시

### 입력·선택
- 주문정보(회원정보로 미리 채움, 잔금 결제는 원 주문 값으로 수정 불가)
  - 주문하시는 분(필수)
  - 주소(필수): 우편번호 / 주소 / 상세주소, 우편번호 검색(잔금 결제에서는 쓸 수 없음)
  - 휴대전화(필수, 중요한 알림이 문자로 간다는 안내)
  - 연락처 2(선택)
  - 이메일(필수, 주문 처리 과정이 메일로 간다는 안내)
- 배송정보(잔금 결제는 원 주문 값으로 수정 불가)
  - 배송지 지정 방식 선택(하나): 주문자와 동일 / 기본배송지 / 새로운 배송지(저장된 배송지 고르기로 이어짐)
  - 받으시는 분(필수)
  - 배송지(필수): 우편번호 / 주소 / 상세주소, 우편번호 검색
  - 연락처 1(필수)
  - 연락처 2(선택)
  - 희망배송일(날짜, 선택)
  - 배송방법 선택(하나, 기본은 기본배송/택배): 기본배송/택배 / 퀵서비스 / 고속버스화물 / 방문수령(픽업장소 협의). 배송비는 견적서에 포함된다는 설명
  - 배송메세지(자유 입력, 선택)
- 포인트
  - 사용 포인트 입력(0 ~ 보유 포인트, 결제금액을 넘으면 자동으로 낮춤)
  - 모두 사용
  - 후불결제 요청이면 포인트 사용 불가(0으로 처리)
- 결제수단 선택(하나, 기본은 신용·체크카드): 신용·체크카드 / 무통장입금 / 후불결제 요청(잔금 결제에서는 없음)
- 결제 희망일(날짜, 후불결제 요청일 때만, 필수)
- 증빙서류 선택(하나, 무통장입금·후불결제 요청일 때만, 기본은 미발행, 잔금 결제는 원 주문 값): 세금계산서 발행 / 현금영수증 발행 / 미발행
  - 세금계산서 발행이면: 사업자등록번호(필수, 형식 자동 맞춤, 회원 사업자번호로 미리 채움) / 계산서 이메일(선택, 비우면 주문자 이메일로 발송, 회원 담당자 이메일로 미리 채움)
  - 현금영수증 발행이면: 발행 용도 선택(하나): 개인(소득공제) / 사업자(지출증빙)(기업 회원은 사업자가 기본) + 휴대폰 번호(필수, 형식 자동 맞춤) 또는 사업자등록번호(필수)
- 취소/환불 정책 동의(필수, 잔금 결제는 이미 동의한 상태로 표시)

### 할 수 있는 일
- 견적서 보기
- 등록된 견적서 파일 보기 / 등록된 견적서 없음 표시(존재 여부 불확실)
- 취소/환불 정책 보기
- 저장된 배송지 고르기(새로운 배송지를 고르면)
  - 저장된 배송지 목록(배송지명 · 받는 분, 기본배송지 표시, 우편번호·주소·상세주소, 휴대전화)
  - 배송지 선택(배송정보에 채움)
  - 배송지 관리로 이동
  - 닫기
- 결제하기(진행 중 상태 표시)
  - 신용·체크카드: 외부 카드 결제창으로 결제 → 카드 결제 처리를 거쳐 주문 완료로 이동
  - 무통장입금·후불결제 요청: 주문 완료 안내(주문번호 포함) → 주문 완료로 이동

### 안내·상태
- 로그인 회원만(비로그인은 로그인으로 이동)
- 본인 견적이 아니거나 결제할 수 없는 상태·정지 회원 등이면 비정상 접근 안내 후 되돌아감
- 기본배송지 없음 안내(배송지 관리에서 등록하라는 안내)
- 저장된 배송지 없음 안내
- 필수 항목 미입력 안내(항목별)
- 이메일 형식 오류 안내
- 취소/환불 정책 미동의 안내
- 결제 희망일 미선택 안내
- 증빙서류 입력 오류 안내(사업자등록번호 미입력·자릿수 오류, 휴대폰 번호 미입력·형식 오류, 계산서 이메일 형식 오류, 서버 거절 사유). 결제하기를 누를 때만 표시되고 고치면 바로 사라짐
- 우편번호 형식 오류 안내
- 입력값 길이 초과 안내
- 결제·배송방법 확인 안내
- 결제할 수 없는 견적 안내
- 견적 금액이 바뀌었으니 새로고침 후 다시 확인하라는 안내
- 이미 저장된 주문 안내
- 후불결제 요청 시 포인트 사용 불가 안내
- 사용 가능 포인트 초과 안내
- 카드 결제창 불러오기 실패 안내
- 카드 결제 진행 실패 안내
- 주문 저장 실패 안내

## 카드 결제 처리
카드 결제 인증 결과를 받아 승인 후 주문을 확정한다. 별도 내용 없이 처리 중 상태와 안내만 있다.

### 안내·상태
- 처리 중 상태(성공하면 주문 완료로, 확정 결과에 이동할 곳이 없으면 마이페이지 주문내역으로 이동)
- 카드 승인은 됐지만 주문 확정 중 오류 안내 → 마이페이지 주문내역으로 이동
- 다음 실패 안내 후 마이페이지 주문내역으로 이동
  - 결제 세션 확인 불가 안내(다시 결제 요청)
  - 카드 인증 취소·실패 안내
  - 결제 요청 만료·불일치 안내(30분 초과 등)
  - 결제 인증정보와 주문정보 불일치 안내(결제창을 연 뒤 견적 금액이 바뀐 경우 포함, 이때는 승인하지 않음)
  - 결제 인증정보 위변조 감지 안내
  - 카드 승인 오류 안내(승인 서버 무응답, 승인 응답 위변조, 결제사 오류, 승인 미완료)

## 주문 완료
결제 주문 완료 또는 견적·시안 요청 접수 완료를 알린다.

### 보여 주는 정보
- 완료 표시
- 완료 제목(요청 접수인지 결제 주문인지에 맞춰 다름)
- 안내(요청 접수: 담당자가 확인 후 견적 또는 시안을 안내 / 결제 주문: 정상 완료) + 주문 내역은 마이페이지에서 확인 가능
- 요청 접수일 때: 요청번호 / 요청 유형(시안 요청 또는 견적 요청)
- 결제 주문일 때: 주문번호 / 결제금액 / 결제수단(후불결제 요청 포함)

### 할 수 있는 일
- 마이페이지(주문내역)로 이동

### 안내·상태
- 로그인 회원만(비로그인은 로그인으로 이동)
- 본인 주문·요청을 찾을 수 없으면 마이페이지 주문내역으로 이동

## 비회원 개인정보처리방침
회원이 아닌 사람이 문의·신청할 때 받는 개인정보 항목과 보관 기간을 안내한다. 고객센터 1:1 문의의 비회원 동의 자세히보기와 약관 묶음에서 들어온다.

### 보여 주는 정보
- 페이지 제목(이전 방침을 볼 때는 이전 방침임을 표시)
- 약관 묶음 이동: 이용약관 / 개인정보처리방침 / 비회원 개인정보처리방침(현재 페이지 표시) / 취소/환불 정책
- 도입 설명(비회원 1:1 문의·파트너십 문의, 회사소개 사이트의 견적 문의·샘플 신청·협력업체 신청 때 적용, 전체 내용은 개인정보처리방침에 있음)
- 시행일(설정된 시행일, 없으면 고쳐 쓴 날과 게시일부터 적용)
- 목차(항목이 많을 때만, 현재 비회원 방침은 해당 없음)
- 받는 항목과 쓰는 곳(접수 경로별 받는 항목·쓰는 곳): 1:1 문의(비회원) / 파트너십 문의 / 회사소개 사이트 견적 문의 / 샘플 신청 / 협력업체 신청
- 보관 기간: 문의·견적·샘플은 처리 후 1년 / 협력업체 신청 3년 / 주문·계약으로 이어지면 법정 기간(5년)
- 동의하지 않을 권리(대표 전화번호 포함)
- 더 자세한 내용 안내
- 관리자가 직접 쓴 방침 문구(관리자가 직접 쓴 문구로 표시하도록 정했거나 이전 방침을 볼 때, 자동 생성 내용 대신 그 글을 그대로 표시)

### 할 수 있는 일
- 개인정보처리방침 보기
- 이전 방침 보기(이전 방침 글이 있을 때만)
- 약관 묶음 안의 다른 약관으로 이동

### 안내·상태
- 방침 내용 불러오기 실패 안내(급한 문의 전화번호 포함)
- 직접 쓴 문구가 비어 있으면 내용 없음 안내

## 관심상품 담기·빼기
상품 목록의 각 상품, 상품 상세, 마이페이지 관심상품 목록에서 공통으로 쓰는 기능.

### 보여 주는 정보
- 관심상품 담김 여부(같은 상품이 여러 곳에 있으면 모두 함께 바뀜)
- 마이페이지 관심상품 개수

### 할 수 있는 일
- 관심상품 담기 / 빼기(로그인 회원만)
- 마이페이지 관심상품 목록에서 빼기(목록에서 바로 사라지고 개수 갱신)
- 마이페이지 관심상품 전체 삭제(삭제 전 확인)

### 안내·상태
- 비로그인 시 로그인 필요 안내 → 로그인 후 원래 페이지로 돌아옴(상품 상세는 고른 옵션 유지)
- 상품 미지정·상품 없음 안내
- 담기·빼기·전체 삭제 결과 안내(존재 여부 불확실)
- 관심상품이 0개가 되면 전체 삭제가 사라지고 빈 상태 안내
- 관심상품 변경 실패 안내
- 관심상품 전체 삭제 실패 안내

## 화면 없는 것
- 장바구니 처리(cart-api.php) — 로그인 회원만. 상품 상세에서 장바구니 담기(수량·포장 필수, 인쇄 상품은 인쇄 방법·인쇄 부위 필수, 첨부파일 최대 10개·파일당 10MB·합계 100MB·이미지·PDF·디자인 파일·압축 파일만, 상품 없음·필수 미입력 안내), 상품 삭제·선택 삭제, 사이즈 수량 수정, 견적·시안 요청 접수(인쇄 상품이 있으면 시안 요청, 없으면 견적 요청, 접수번호 생성, 접수한 상품은 장바구니에서 빠짐)
- 견적·시안 요청 접수 후 알림 — 고객에게 주문 접수 안내 메일(주문자 이메일, 없으면 회원 이메일, 마이페이지 바로가기 포함), 관리자에게 새 시안·주문 요청 메일
- 장바구니 주문 접수 중계(quote_pr_api.php) — 장바구니 주문하기를 받아 견적·시안 요청 접수 처리로 넘김
- 주문 저장 처리(order-api.php) — 결제하기 검사·저장, 포인트 차감, 요청 상태 변경(무통장입금은 입금 대기, 후불결제 요청은 후불 요청, 카드는 결제 완료 후 상품 준비중), 잔금 결제는 결제 정보만 반영

# 견적·맞춤작업복·안전용품·시안·납품사례·파트너 제휴 요소 목록

## 견적문의 안내
견적문의를 시작하기 전에 진행 단계와 참고 사항을 알려 주는 페이지.

### 보여 주는 정보
- 페이지 제목(견적문의)
- 견적문의 소개 문장(상품·인쇄 방법·수량을 알려 주면 담당자가 맞춤 견적을 안내)
- 평균 답변 소요 시간 안내(영업일 기준 1~2일)
- 진행 3단계 안내: 상품 검색 또는 상품명 직접 입력 → 수량·옵션·인쇄 정보 입력 → 담당자 확인 후 답변
  - 단계마다 단계 번호, 단계 이름, 짧은 설명
  - 단계마다 그림(관리자가 바꿀 수 있음, 없으면 빈 상태)
- 참고 사항 목록
  - 쇼핑몰 상품은 검색으로 고르고, 없는 상품은 상품명과 참고 이미지로 문의 가능
  - 견적문의는 회원만 이용 가능
  - 제출한 견적 문의 내역은 마이페이지에서 확인 가능

### 할 수 있는 일
- 견적문의 하러 가기(견적문의로 이동)

### 안내·상태
- 비회원에게만: 회원 전용이니 먼저 로그인하라는 안내

## 견적문의 — 비회원 안내
비회원이 견적문의에 들어왔을 때 회원 전용임을 알리고 로그인·가입·상담으로 이끄는 화면.

### 보여 주는 정보
- 페이지 제목(견적문의)
- 견적문의는 회원만 이용할 수 있다는 안내
- 견적문의 소개 설명
- 진행 3단계 미리보기(견적문의 안내와 같은 단계 이름·설명), 첫 단계가 현재 단계임을 표시

### 할 수 있는 일
- 로그인(로그인 후 견적문의로 돌아옴, 상품 상세에서 왔으면 그 상품 정보를 이어받은 견적문의로 돌아옴)
- 회원가입(가입 후 같은 곳으로 돌아옴)
- 간편 로그인: 카카오 / 네이버 / Google(로그인 후 같은 곳으로 돌아옴)
- 전화상담(사이트 대표 전화번호로 전화 걸기, 번호는 사이트 설정 값)
- 카카오톡 상담(카카오톡 채널로 이동)

## 견적문의 — 대화형 입력
회원이 질문에 하나씩 답하며 상품별 견적 정보를 입력하는 기본 견적문의 화면.

### 보여 주는 정보
- 페이지 제목(견적문의)
- 견적문의 이용 안내(질문에 답한 뒤 미리보기로 확인하고 보내기, 담당자 연락, 상담 시간: 주중 10시~18시, 점심 12시~13시) — 열고 닫을 수 있음
- 진행률(답한 질문 비율, 백분율)
- 대화 시작 인사
- 질문과 고객의 답이 차례로 쌓이는 대화 기록
- 상대가 입력 중임을 나타내는 표시
- 두 번째 상품부터 질문마다 몇 번째 상품인지 표시

### 입력·선택
- 상품마다 반복:
  - 상품 유형 선택(하나, 필수): 쇼핑몰 내 상품 / 쇼핑몰에 없는 상품 — 바꾸면 그 뒤 답이 초기화됨
  - (쇼핑몰 내 상품이면) 상품 검색어 입력 + 검색 결과 목록에서 상품 고르기
  - (쇼핑몰에 없는 상품이면) 상품명 입력(필수, 최대 200자)
  - 상품·디자인 이미지 첨부(선택, 건너뛰기 가능) — 쇼핑몰에 없는 상품이거나 상품 상세에서 파일을 넘겨받았을 때만. 이미지·PDF·문서·한글·압축파일, 상품당 최대 5개, 파일당 20MB, 파일 추가·개별 삭제, 현재 개수/한도 표시
  - 수량 입력(필수, 숫자, 1개 이상, 단위 개)
  - 상품 옵션 입력(선택, 색상·사이즈 등, 최대 500자)
  - 포장 방법 선택(하나, 선택): 기본포장 / 고급포장 / 상담 후 결정
  - 로고 인쇄 여부 선택(하나, 필수): 인쇄 있음(로고·문구 인쇄 또는 자수) / 인쇄 없음
  - (인쇄 있음이면) 인쇄방법 선택(하나, 선택): 열전사 인쇄 / 나염 인쇄 / 자수 인쇄 / 기타 — 상품 상세에서 다른 인쇄방법이 넘어오면 그 값도 선택지로 추가
  - (인쇄 있음이면) 로고 파일 첨부(선택, 건너뛰기 가능): AI·EPS·PDF·PSD·PNG·JPG·GIF·ZIP, 최대 3개, 파일당 20MB, 지금 없으면 상담 때 보내도 된다는 안내
  - (인쇄 있음이면) 인쇄 부위 및 설명 입력(선택, 긴 글, 최대 2000자)
  - 납품희망일 선택(선택, 날짜)
  - 기타사항 입력(선택, 긴 글, 최대 2000자)
  - 다른 상품도 함께 문의할지 선택(하나, 필수): 예(다음 상품 질문 반복) / 아니요(진행)
- 마지막 상품 다음:
  - 연락받을 정보 확인·수정(회원 정보로 미리 채움): 회사명(필수, 100자), 담당자(필수, 50자), 연락처(필수, 30자)
  - 요청사항 입력(선택, 긴 글, 2000자) + 검토 후 상담원이 연락처로 전화한다는 안내

### 할 수 있는 일
- 이미 답한 질문으로 돌아가 답 수정
- 선택 질문 건너뛰기
- 입력한 답으로 다음 질문 진행
- 견적서 미리보기 보기(보기 전용, 견적 요청은 할 수 없음)
- 최종 견적문의 보내기 → 성공하면 접수 완료 메시지와 문의번호를 알리고 마이페이지 견적문의 내역으로 이동
- 상품 상세에서 견적문의로 넘어온 경우 첫 상품의 정보와 인쇄 파일을 미리 채움(1시간 이내, 파일당 10MB 이하, 최대 5개)

### 안내·상태
- 입력 내용을 확인한 뒤 보내 달라는 마지막 단계 안내 + 미리보기로 확인할 수 있다는 안내
- 상품 검색 중 안내
- 검색 결과 없음 안내(앞 질문을 고쳐 쇼핑몰에 없는 상품으로 문의할 수 있다는 안내 포함)
- 상품 불러오기 실패 안내
- 수량 미입력·1 미만 안내
- 첨부 개수 초과 안내, 파일 용량(20MB) 초과 안내
- 첨부 한도 초과 안내: 상품당 상품·디자인 이미지와 로고 합쳐 5개, 전체 20개, 합계 100MB
- 접수 진행 중 표시
- 접수 실패 안내
- 브라우저 스크립트를 쓸 수 없을 때 전화 문의 안내

## 견적문의 — 한 화면 입력 양식
대화형 대신 한 화면에서 여러 상품과 연락처를 한꺼번에 적는 회원용 견적문의 양식(대체 화면).

### 보여 주는 정보
- 페이지 제목(견적문의)
- 평일 고객상담 전화번호
- 입력 단계 진행 표시(지금 보고 있는 단계, 필수값을 다 채운 단계 완료 표시)
- 상품마다 상품 번호
- 입력 요약
  - 상품별 상품명(없으면 상품 번호)과 수량(없으면 비어 있음 표시)
  - 상품·디자인 이미지 전체 개수
  - 입력한 회사명·담당자·연락처
  - 필수값 채운 비율
- 연락처 묶음 이름(회원용 주문 양식)

### 입력·선택
- 상품마다:
  - 상품 유형 선택(하나, 필수): 쇼핑몰 내 상품(기본) / 쇼핑몰에 없는 상품 — 바꾸면 상품명 초기화
  - 상품명(필수): 쇼핑몰 내 상품이면 상품 검색으로만 채움, 쇼핑몰에 없는 상품이면 직접 입력
  - 상품·디자인 이미지 첨부(선택, 여러 개): 이미지·PDF·문서·한글·압축파일, 상품당 최대 5개, 파일당 20MB, 선택한 파일 이름·용량 목록, 개별 삭제 — 쇼핑몰 내 상품이면서 첨부가 없으면 나오지 않음
  - 수량(필수, 숫자, 1 이상, 기본 1)
  - 상품 옵션(선택, 색상·사이즈 등)
  - 포장 선택(하나, 선택): 기본포장 / 고급포장 / 상담 후 결정
  - 인쇄방법 선택(하나, 선택): 열전사 인쇄 / 나염 인쇄 / 자수 인쇄 / 기타(상품 상세에서 다른 값이 오면 추가)
  - 인쇄 부위 및 설명(선택, 긴 글: 인쇄 부위·로고 크기·색상 등)
  - 납품희망일(선택, 날짜)
  - 기타사항(선택, 긴 글)
- 연락처 정보(회원 정보로 미리 채움):
  - 회사명(필수)
  - 담당자(필수)
  - 연락처(필수)
  - 요청사항(선택, 긴 글) + 검토 후 상담원이 연락처로 전화한다는 안내

### 할 수 있는 일
- 상품 추가
- 상품 삭제
- 상품 검색 열기(상품명 입력을 누르거나 상품검색으로)
- 다음(검사 후 견적서 미리보기로 이동, 미리보기에서 견적 요청)
- 전화상담(전화 걸기)
- 카카오톡 상담(카카오톡 채널로 이동)
- 상품 상세에서 넘어온 경우 첫 상품 정보와 인쇄 파일 미리 채움(파일 최대 10개, 파일당 10MB 이하)

### 안내·상태
- 상품이 하나도 없을 때 상품을 추가하라는 빈 상태 안내
- 첨부 상품당 5개 초과 안내, 파일 20MB 초과 안내
- 다음 진행 전 검사 안내: 상품 1개 이상 필요, 몇 번째 상품 미선택, 몇 번째 상품 수량 확인, 첨부 전체 20개 초과, 첨부 합계 100MB 초과, 회사명·담당자·연락처 미입력

## 견적문의 — 상품 검색
견적문의에서 쇼핑몰 상품을 찾아 상품명으로 채우는 검색 화면.

### 보여 주는 정보
- 제목(상품 검색)
- 검색어가 없을 때 추천 상품(무작위 20개)
- 검색했을 때 검색 결과와 총 개수
- 결과 상품마다: 대표 이미지, 색상 표시(최대 5개, 넘치면 나머지 수), 사이즈 범위, 상품명(상품 상세로 이동), 가격(판매가가 없으면 견적문의로 표시)

### 입력·선택
- 상품명 검색어 입력(최대 100자)
- 검색어 자동완성 목록(최대 6개, 상품명 중 검색어 강조 + 카테고리명), 키보드로 고르기
- 결과에서 상품 고르기 → 그 상품으로 상품명이 채워지고 검색이 닫힘

### 할 수 있는 일
- 검색
- 검색어 지우기
- 닫기

### 안내·상태
- 상품 불러오는 중 / 찾는 중 안내
- 등록된 상품 없음 안내
- 검색 결과 없음 안내
- 검색어가 너무 김 안내
- 불러오기 오류 안내

## 견적서 미리보기
견적문의 입력값을 견적서 형태로 미리 보여 주고 거기서 견적 요청까지 할 수 있는 화면(저장하지 않음).

### 보여 주는 정보
- 견적서 제목 + 미리보기 표시
- 수신처(입력한 회사명), 담당자, 연락처, 견적일자(오늘), 유효기간(견적일로부터 15일), 견적금액(0원, 부가세 포함)
- 공급자 정보: 회사 로고, 주소, 전화번호, 사업자등록번호, 대표이사 이름, 대표 직인, 사이트 주소
- 상품마다: 번호와 상품명, 옵션, 포장, 인쇄방법, 인쇄내용, 수량, 단가(0원), 금액(0원), 비고(납기일 + 기타사항, 없으면 비어 있음 표시), 첨부파일 이름 목록(있을 때만)
- 총 합계 금액(0원, 부가세 포함)
- 요청사항은 나오지 않음

### 할 수 있는 일
- 닫기

- 총 합계 금액(관리자가 직접 정한 금액이 있으면 그 값, 없으면 단가 합계에 부가세 10% 더한 값)

## 맞춤작업복 견적문의
기업 로고·디자인을 넣은 맞춤 의류 제작 견적을 요청하는 회원 전용 화면.

### 보여 주는 정보
- 대표 사진
- 페이지 제목(맞춤작업복) + 견적문의 표시
- 소개 제목과 설명(기업 로고와 디자인을 반영한 맞춤 의류 제작)
- 비회원에게만: 회원 전용 안내

### 입력·선택
- 회사/단체명(필수, 100자, 회원 정보로 미리 채움)
- 담당자명(필수, 50자, 회원 이름으로 미리 채움)
- 연락처(필수): 앞자리 선택(휴대폰·지역번호·070) + 가운데 3~4자리 + 끝 4자리, 숫자만 — 회원 휴대폰으로 미리 채움
- 이메일(선택): 아이디 + 도메인 직접 입력 또는 도메인 선택(naver.com / daum.net / hanmail.net / gmail.com / nate.com / kakao.com) — 회원 이메일로 미리 채움
- 제작 품목(필수, 200자, 예: 티셔츠·작업복·조끼)
- 제작 수량(필수, 숫자, 최소 100장) + 최소 주문 수량 100장 안내
- 희망 납기일(필수, 날짜, 오늘 이후만)
- 기존 제품 샘플 제공 여부 선택(하나, 필수): 제공 가능 / 제공 불가 + 설명
- 디자인 파일 첨부(선택, 여러 개): 이미지·PDF·문서·한글·압축파일, 최대 5개, 파일당 20MB, 합계 100MB
- 기타 요청사항(선택, 긴 글, 3000자: 원단·디자인·기능·납품 조건 등)
- 개인정보 수집·이용 동의(필수) + 자세히 보기(개인정보처리방침으로 이동)

### 할 수 있는 일
- 취소(이전 화면으로, 바깥에서 왔으면 첫 화면으로)
- (회원) 문의 접수하기 → 성공하면 접수 완료와 문의번호를 알리고 마이페이지 맞춤작업복 문의 내역으로 이동

- (비회원) 로그인 / 회원가입 / 간편 로그인(카카오·네이버·Google) — 모두 이 화면으로 돌아옴

### 안내·상태
- 비회원에게는 입력 항목이 보이지만 모두 입력 불가
- 입력 오류 안내: 회사/단체명, 담당자명, 연락처 형식, 이메일 형식, 제작 품목, 수량 100장 미만, 희망 납기일, 샘플 여부, 첨부 5개 초과, 파일당 20MB 초과, 합계 100MB 초과, 개인정보 동의 안 함, 서버 오류

## 시안확인(주문)
주문(견적요청)에 관리자가 올린 시안을 고객이 보고 승인하거나 수정을 요청하는 화면. 마이페이지 주문 내역의 시안확인으로 열림.

### 보여 주는 정보
- (시안과 견적을 함께 받은 건만) 견적 요약
  - 견적 금액(부가세 포함)
  - 품목 목록(품목명·옵션·수량)
- 시안 이미지(본인 건만 볼 수 있음)
  - 품목이 2개 이상이면 품목명별로 묶어서
  - 품목에 연결되지 않은 시안 이미지도 함께

### 입력·선택
- (시안과 견적을 함께 받은 건만) 수정 요청 내용 입력(긴 글, 1000자)

### 할 수 있는 일
- (시안과 견적을 함께 받은 건만) 견적서 보기(주문 견적서로 이동)
- (시안과 견적을 함께 받은 건만) 수정 요청 보내기(확인 후) → 상태를 접수 대기로 되돌리고 시안 이력에 기록, 관리자에게 요청 내용과 함께 알림, 마이페이지 주문 내역 새로 고침
- 확인(닫기)
- (시안 완료 상태일 때) 시안 승인(확인 후)
  - 시안과 견적을 함께 받은 건: 시안·견적 승인 → 견적 완료 상태로, 결제 가능하면 바로 결제할지 물은 뒤 주문 결제로 이동, 관리자에게 알림
  - 시안만 받은 건: 시안 승인 → 이후 관리자가 견적 진행, 관리자에게 알림

### 안내·상태
- 로그인 회원 본인 건만(비로그인이면 로그인으로 이동)
- 잘못된 요청 안내
- 시안 정보를 찾을 수 없음 안내
- 등록된 시안 이미지 없음 안내(접수 대기 상태이거나 시안이 없을 때)
- 수정 내용 미입력 안내
- 수정 요청 접수 완료 안내
- 승인 완료 안내(시안·견적 승인 / 시안 승인)

## 견적문의 시안 보기

### 보여 주는 정보

- 시안 이미지 목록

### 할 수 있는 일
- 시안 이미지 크게 보기(원본 이미지 열기)
- 확인(닫기)

### 안내·상태
- 로그인 회원 본인 문의만
- 잘못된 요청 안내
- 등록된 시안 이미지 없음 안내
- 승인·수정 요청 기능은 없음

# 회원 영역 요소 목록 (로그인·회원가입·마이페이지·수신거부)

## 로그인
아이디(또는 이메일)·비밀번호 로그인과 Google·카카오·네이버 간편 로그인.

### 보여 주는 정보
- 페이지 제목(로그인)
- 회사 소개 문구(많은 기업이 선택한 산업현장 공급 파트너, 단체복부터 산업용품까지)
- 대표 사진(산업현장 작업자)

### 입력·선택
- 아이디 또는 이메일 (필수)
- 비밀번호 (필수)
- 로그인 상태 유지 선택 (선택하면 30일 유지)

### 할 수 있는 일
- 로그인
- 아이디·비밀번호 찾기 안내 (찾기 기능 존재 여부 불확실)
- 회원가입으로 이동 (비회원 안내와 함께)
- Google로 로그인
- 카카오로 로그인
- 네이버로 로그인
- 로그인 뒤 원래 보던 페이지로 돌아가기 (회원가입·간편 로그인을 거쳐도 유지)

### 안내·상태
- 이미 로그인한 회원은 바로 원래 보던 페이지(없으면 첫 화면)로 이동
- 아이디·비밀번호 미입력 안내
- 로그인 실패 안내(아이디·비밀번호 불일치)
- 짧은 시간 안에 실패가 너무 많으면 잠시 뒤 다시 시도 안내
- 통신 오류 안내
- 간편 로그인 실패 안내(설정 미완료, 보안 검증 실패, 취소, 기타 오류)
- 이용할 수 없는 계정 안내
- 로그인 처리 중 상태 표시
- 간편 가입으로 비밀번호가 없는 회원은 아이디·비밀번호 로그인 불가
- 처음 간편 로그인한 사람은 회원가입 정보 입력으로 이어짐

- 자동등록방지 미입력 / 불일치·만료 안내(그림 자동 교체, 시도 횟수 제한)

## 마이페이지 — 배송지 관리
주문할 때 쓸 배송지 목록 관리(최대 20개).

### 보여 주는 정보
- 배송지마다: 기본 배송지 표시, 배송지명, 받는 분, 우편번호·주소·상세주소, 휴대전화

### 입력·선택
- (배송지 추가·수정) 배송지명 (필수, 50자)
- (배송지 추가·수정) 받는 분 (필수, 50자, 새로 추가할 때 회원 이름으로 미리 채움)
- (배송지 추가·수정) 휴대전화 (필수, 010 형식, 하이픈 자동 입력, 새로 추가할 때 회원 정보로 미리 채움)
- (배송지 추가·수정) 우편번호 (주소 검색으로만 채움)
- (배송지 추가·수정) 주소 (필수, 주소 검색으로만 채움)
- (배송지 추가·수정) 상세주소 (필수)
- (배송지 추가·수정) 기본 배송지로 설정 (이미 기본인 배송지는 해제 불가)

### 할 수 있는 일
- 새 배송지 추가
- 배송지 수정(기존 값 채워짐)
- 기본 배송지로 지정(기본이 아닐 때)
- 배송지 삭제(확인 후, 기본을 지우면 가장 최근 배송지가 기본이 됨)
- 주소 검색(우편번호 서비스)
- 저장 / 취소

### 안내·상태
- 등록된 배송지 없음 안내
- 배송지명·받는 분·휴대전화·주소 입력 오류 안내
- 배송지 최대 20개 초과 안내
- 처리 실패·통신 오류 안내
- 첫 배송지는 자동으로 기본 배송지

## 고객센터 — 자주 묻는 질문

  - 질문

- 분류 선택(전체 + 운영자가 등록한 분류들, 하나 선택, 기본은 전체, 검색어와 함께 적용)

### 안내·상태

- 검색 결과 없음 안내

## 고객센터 — 주문방법
인쇄가 있는 주문과 없는 주문의 진행 단계를 그림과 함께 설명한다.

### 보여 주는 정보
- 제목(주문방법)
- 인쇄 있는 주문 안내
  - 도입 설명(시안 승인 뒤 결제)
  - 1단계: 상품 옵션·수량 선택(인쇄 있음 선택) + 화면 예시 이미지
  - 2단계: 인쇄방법·인쇄 자리·설명 입력 + 화면 예시 이미지 + 인쇄 비용 별도 추가 안내
  - 3단계: 장바구니 담기·주문하기 + 화면 예시 이미지 + 주문하기 후 나오는 화면 설명·예시 이미지
  - 4단계: 시안·견적서 확인 및 승인(견적서 확인 / 시안확인 / 시안 승인 / 수정 요청)
    - 마이페이지 주문 내역에서 시안확인 선택 + 예시 이미지
    - 별도 창에서 시안 이미지 확인 후 승인 또는 수정 요청 + 예시 이미지
    - 견적서 확인 + 예시 이미지
  - 5단계: 결제 진행
    - 마이페이지 주문 내역에서 결제진행 선택 + 예시 이미지
    - 주문서에서 주문자·배송 정보 확인 + 설명·예시 이미지
    - 결제수단 선택(신용/체크카드, 무통장입금, 후불결제 요청) + 예시 이미지
    - 취소/환불 정책 동의 후 결제하기 + 예시 이미지
    - 주문 완료 화면 확인 + 예시 이미지
- 인쇄 없는 주문 안내
  - 도입 설명(시안 확인 절차 없음)
  - 1단계: 상품 옵션·수량 선택(인쇄 없음이 기본값) + 화면 예시 이미지
  - 2단계: 바로 장바구니 담기·주문하기 + 화면 예시 이미지
  - 3단계: 장바구니 확인 + 화면 예시 이미지 + 주문하기 후 나오는 화면 설명·예시 이미지
  - 4단계: 견적서 확인(견적서 보기) + 예시 이미지
  - 5단계: 결제 진행(인쇄 있는 주문의 결제 진행과 같은 다섯 과정)
- 주문 전 확인 사항(두 안내에 공통)
  - 선결제 필수(공공기관·학교·관공서 제외)
  - 인쇄 비용 별도
  - 사진과 실제 색상 차이 가능
  - 약 1cm 사이즈 오차
  - 시즌별 원단·부자재 변경 가능
  - 주문제작 특성상 단순 변심 교환·환불 어려움
- 결제 관련 안내(두 안내에 공통)
  - 결제수단 3종
  - 후불결제 요청 대상·예외
  - 세금계산서는 무통장입금 때만, 1~3영업일 안에 이메일 발송
  - 선발행·날짜 지정은 결제 전 전화 요청
  - 누락 시 익월 10일까지 추가 신청

### 입력·선택
- 안내 종류 선택(인쇄 있는 주문 / 인쇄 없는 주문, 하나, 기본은 인쇄 있는 주문)

### 할 수 있는 일

### 안내·상태

- 답변 전이면 확인 중 안내

## 고객센터 — 비회원 1:1 문의 확인
비회원이 등록할 때 쓴 이름·비밀번호로 자기 문의를 찾아본다. 비로그인일 때만.

### 보여 주는 정보
- 조회 결과(조회 성공 후)
  - 문의 총 건수
  - 문의 목록: 제목, 작성일시, 상태(접수완료 / 답변완료)
  - 문의 상세(목록에서 하나를 고르면): 제목, 문의번호, 상태, 작성일, 답변일(없으면 없음 표시), 문의 내용, 관리자 답변
- 관리자 답변 첨부파일 내려받기(존재 여부 불확실, 조회 후 30분 동안만)

### 입력·선택
- 이름(필수, 문의 등록 때 입력한 이름)
- 비밀번호(필수, 문의 등록 때 설정한 비밀번호)

### 할 수 있는 일
- 문의 확인(조회)

### 안내·상태
- 문의 접수 완료 안내(방금 등록한 경우, 문의번호 포함)
- 이름·비밀번호 미입력 안내
- 이름 또는 비밀번호 불일치 안내
- 조회 시도 횟수 초과 안내(10분에 5회 실패 시 10분 뒤 재시도)
- 회원 문의는 로그인 후 확인 안내
- 조회 성공 시 비밀번호 입력값 비움
- 등록된 문의 없음 안내
- 답변 전이면 확인 중 안내

## 고객센터 — 1:1 문의 작성
회원·비회원 모두 1:1 문의를 등록한다.

### 보여 주는 정보
- 제목(문의 작성)

### 입력·선택
- 이름(필수, 회원은 회원 정보로 자동 입력·수정 불가)
- 전화번호(필수, 회원은 자동 입력·수정 불가)
- 이메일(선택, 형식 검사, 회원은 자동 입력·수정 불가)
- 문의 비밀번호(필수, 비회원만, 6~72자)
- 문의 제목(필수, 최대 200자)
- 문의 내용(필수, 최대 10,000자)
- 자동등록방지 숫자 6자리 입력(필수, 비회원만, 숫자 그림 보고 입력, 새 숫자 받기 가능)
- 비회원 개인정보 수집·이용 동의(필수, 비회원만, 비회원 개인정보처리방침 자세히 보기는 새 창)

### 할 수 있는 일
- 취소(이전 페이지로)
- 문의 등록
- 등록 시 운영자에게 새 문의 알림 메일 발송
- 등록된 문의는 상담 요청으로 집계
- 회원이면 등록 시 회원 정보의 이름·휴대폰·이메일로 저장

### 안내·상태
- 필수 항목 미입력 안내
- 비회원 비밀번호·자동등록방지 숫자 미입력 안내
- 비밀번호 6자 미만 안내
- 자동등록방지 숫자 6자리 미입력 안내
- 개인정보 동의 안 함 안내
- 이메일 형식 오류 안내
- 제목·내용 확인 안내
- 문의자 정보·비밀번호 확인 안내
- 자동등록방지 숫자 불일치 안내(여러 번 틀리거나 시간이 지나면 새 숫자 필요)
- 회원 정보 확인 불가 안내
- 잘못된 요청(페이지 새로고침 필요) 안내
- 처리 중에는 다시 등록할 수 없음
- 접수 완료 안내(문의번호 포함) 뒤 문의 접수 완료 상태로 1:1 문의를 다시 보여 줌
- 실패 시 오류 안내, 비회원이면 자동등록방지 숫자 새로 받음

## 개인정보처리방침
개인정보처리방침을 보여 준다. 기본은 항목별로 정리된 문서, 운영자가 직접 입력한 글을 쓰도록 설정했거나 이전 방침을 볼 때는 입력한 글을 그대로 보여 준다.

### 보여 주는 정보

- 적용일
- 목차(각 항목으로 바로 이동)
- 방침 항목
  - 개인정보 이용 목적
  - 수집하는 개인정보 항목
  - 쿠키와 방문 기록(행태정보): 쿠키·저장 이름 / 쓰는 곳 / 보관 기간 목록 + 방문 기록 설정 바꾸기(방문 기록 동의를 목적별 설정 상태로 다시 띄움)
  - 보관 기간: 기록 / 보관 기간 / 근거·설명 목록
  - 파기 절차와 방법
  - 제3자 제공
  - 처리 위탁 업체
  - 국외 이전 정보
  - 정보주체의 권리와 행사 방법
  - 안전성 확보 조치
  - 개인정보 보호책임자: 구분 / 내용 목록
  - 권리 침해 구제 방법
  - 적용일과 변경 내용
- 회사 정보·보관 기간은 운영자 설정값 반영
- 이전 방침 본문(운영자가 입력한 글, 이전 방침을 볼 때)

  - 화면 이용 기록(화면 기록 기능이 켜졌을 때만)
  - 광고 효과 측정(광고 측정이 켜졌을 때만)

- 동의

- 선택하면 바로 닫힘
