06Principles

고객이 중요하게 보는세 가지

01

가격

대량 매입을 통해 확보한 가격 경쟁력을 고객 공급가에 반영합니다.

02

납기

발주 전에 재고와 공급 가능 일정을 확인하고, 주문 확정 후 검수와 납품 일정을 관리합니다.

03

구매 편의

여러 품목의 견적을 한곳에서 요청할 수 있도록 하고, 주문 조건을 확인하기 쉽게 안내합니다.

07How it works

견적부터 납품까지이렇게 진행합니다

품목 선정, 사이즈 취합, 로고 시안 확인부터 납품까지 단체복 구매 과정을 지원합니다.

  1. 0START

    가입과 승인

    사업자등록증을 확인한 뒤 기업회원으로 승인해 드립니다.

    가입
    사업자등록증을 제출해 기업회원으로 가입합니다.
    담당자 배정
    기업 주문은 담당자가 1:1로 맡아 견적부터 납품 협의까지 안내합니다.
  2. 1STEP 01

    문의와 견적

    사용 목적과 품목, 수량, 규격, 희망 납기를 확인하고 공급 조건을 안내합니다.

    보내실 것
    사용 목적, 품목, 수량, 규격, 희망 납기. 사내 구매 목록으로 보내시면 됩니다.
    받으실 것
    품목별 단가와 예상 납기를 정리해 드립니다.
  3. 2STEP 02

    주문과 제작

    주문 내역을 확인하고, 제작이나 마킹이 필요한 경우 사양과 시안을 조율합니다.

    확인하실 것
    주문 내역. 제작이나 마킹이 필요하면 사양과 시안.
    발주 전 확인
    최종 품목, 수량, 발주 조건을 확인합니다.
  4. 3STEP 03

    검수와 납품

    출고 전에 수량과 제품 상태를 확인하고, 확정한 일정에 맞춰 납품을 관리합니다.

    검수 기준
    주문 내역을 기준으로 품목과 수량을 확인하고, 제작 제품은 확정한 사양과 시안을 기준으로 검수합니다.
    여러 현장
    납품처별 품목과 수량을 확인하고, 분할 납품 가능 여부와 일정을 협의합니다.
  5. 4STEP 04

    재주문과 정기납품

    이전 주문 이력과 고객별 발주 주기를 바탕으로 추가 발주와 정기납품을 지원합니다.

    요청 방법
    추가 발주가 필요할 때 이전 주문을 기준으로 요청하시면 됩니다.
